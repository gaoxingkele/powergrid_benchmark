# Experimental Data Included in This Package

The directories contain the derived records that support the manuscript's four
empirical streams:

- `canonical_v2/`: 1440 GridDB backbone-condition rows and analysis tables.
- `inference_hierarchy/`: finite-corpus inference and composition-sensitivity
  outputs.
- `component/`: component contrasts and independent release checks.
- `constructed_state/`: 25,920 atomic state scores, report tables, and exact
  sign-enumeration results.
- `historical_pool/`: the complete selected v3a replay ledgers, sensitivity
  results, and release manifests supporting 80/100/101 and tie analyses.
- `BIRD_aggregates/`: aggregate method summaries, Holm-adjusted contrasts, and
  the post-run independent audit for the 500-item public-database study.
- `GridDB_Access_Metadata/`: the data card and rights status for the excluded
  raw GridDB database and question corpus.

Raw BIRD databases and the raw GridDB files are excluded under the package's
rights notice. The manuscript therefore states that applicable restricted data
can be requested from the corresponding author, subject to third-party terms.
