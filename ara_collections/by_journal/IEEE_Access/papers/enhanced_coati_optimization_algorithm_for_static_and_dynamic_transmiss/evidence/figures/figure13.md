## Visual description
- **Components**: 25 buses with multiple generators (G) and loads (arrows); voltage levels annotated (230 kV, 138 kV near buses 12/23/18). 36 candidate line paths; 2750 MW total demand.
- **Connections**: solid black = existing lines; red dashed = to-be-added lines without generation resizing; blue dashed = to-be-added lines with generation resizing (concentrated around buses 5, 25, 9, 11, 12, 13, 18).
- **Annotations**: legend distinguishes existing / added-without-resizing / added-with-resizing.
- **What it conveys**: the medium-scale topology and the two optimal expansion plans, corresponding to Tables 16 (without-resizing line additions) and 17 (with-resizing: n5-25:3, n9-11:1). Supports C04, C08.
