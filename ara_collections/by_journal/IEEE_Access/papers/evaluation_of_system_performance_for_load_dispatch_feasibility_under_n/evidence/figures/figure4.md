## Visual description
- **Components**: The 24-bus IEEE Reliability Test System single-line diagram. Buses numbered 1–24 are
  drawn as horizontal bars; generator symbols "G" (circles) attach to the generation buses. Generators
  in this study connect at buses 1, 2, 7, 13, 15, 18, 21, and 23 (per Table 2). Transmission lines
  interconnect the buses across two voltage areas (upper/lower halves typical of the RTS).
- **Connections**: transmission lines link buses (e.g., the ring/mesh of the RTS); exact per-line
  topology is the standard IEEE RTS layout and is not re-transcribed as data here.
- **Annotations**: "G" markers indicate generation buses; bus numbers label each bar.
- **What it conveys**: the network on which N-1 generator contingencies are simulated, locating the
  critical (18, 21, 23) and robust (13, 15, 1) buses within the topology. Supports C02 and C06.
