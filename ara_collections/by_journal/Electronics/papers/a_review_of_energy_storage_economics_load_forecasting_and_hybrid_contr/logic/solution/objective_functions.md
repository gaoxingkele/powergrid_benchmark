# Formalization: Optimization Objectives and State-Estimation Equations

The review presents 11 numbered equations it synthesizes from the literature (not derived anew). They
formalize (a) the multi-objective EMS optimization used with hybrid metaheuristics, and (b) BMS
SoC/SoE state estimation. Transcribed from §4.2 (Eqs 1–5), §5 (Eq 6), and the BMS section (Eqs 7–11).

## Multi-objective optimization objectives (§4.2)

**Eq (1) — Emission minimization**
`F_emissions = Σ_{t=1}^{T} Σ_{g=1}^{G} P_g(t) · EF_g`
where `P_g(t)` = power generated by source g at time t; `EF_g` = emission factor of source g.

**Eq (2) — Network power-loss minimization**
`F_losses = Σ_{t=1}^{T} Σ_{(i,j)∈Ω_l} I_ij²(t) · R_ij`
where `I_ij(t)` = current magnitude in the branch between nodes i, j at time t; `R_ij` = branch resistance; Ω_l = set of network branches.

**Eq (3) — Autonomy maximization (LPSP)**
`F_autonomy = LPSP = [ Σ_{t=1}^{T} L_unmet(t) ] / [ Σ_{t=1}^{T} L_demand(t) ]`
where `L_unmet(t)` = unmet load; `L_demand(t)` = total load demand. Lower LPSP ⇒ higher autonomy / local supply reliability.

**Eq (4) — Total cost minimization**
`F_cost = C_cap + C_op + C_maint + C_deg + C_grid`
capital, operating, maintenance, degradation, and grid-interaction costs respectively. `C_deg` explicitly links dispatch to degradation cost.

**Eq (5) — Weighted multi-objective function**
`F_total = w₁·F_cost + w₂·F_emissions + w₃·F_losses + w₄·F_autonomy`
weighting coefficients w₁…w₄ set by economic/environmental/technical/reliability priorities. Enables GWO-PSO to search a balanced solution rather than optimizing one indicator (C04). Rationale (§4.2): a cost-minimizing dispatch may raise degradation; an autonomy-maximizing one may require more cycling/capacity — so a weighted trade-off is required.

## Expansion-cost objective (§5)

**Eq (6) — Total expansion-cost minimization**
`min C_total = Σ_{t=1}^{T} ( C_network(t) + C_NNS(t) + C_operation(t) + C_loss(t) )`
balances traditional network-reinforcement cost against smart NNS investment, operation, and loss costs; underpins storage-as-NNS siting/sizing (C09).

## BMS state-estimation equations (§ Battery Management Systems)

**Eq (7) — SoC (continuous-time, Coulomb counting)**
`SoC_t = SoC_0 − ( ∫_0^t i(ξ) dξ ) / C_n`
`C_n` = nominal capacity. Limitation: does not account for nonlinear terminal-voltage dynamics (C03).

**Eq (8) — SoE (continuous-time, power integral)**
`SoE_t = SoE_0 − ( ∫_0^t i(ξ)·u(ξ) dξ ) / E_n`
`E_n` = nominal energy; `u(ξ)` = terminal voltage. Captures voltage/temperature-dependent usable capacity → more accurate releasable-energy estimate (C03).

**Eq (9) — SoC operational ratio**
`SoC = [ Remaining Charge (Ah) / Nominal Capacity (Ah) ] × 100`

**Eq (10) — SoE operational ratio**
`SoE = [ Remaining Energy (kWh) / Nominal Capacity (kWh) ] × 100`

**Eq (11) — SoC–SoE quadratic correlation**
`SoE = a · SoC²(k) + b · SoC(k) + c`
a stable positive correlation used for co-estimation cross-referencing and error correction (ref [92]).

## Notes
- Equations (1)–(5) guide optimization-based EMS; (6) governs NNS expansion planning; (7)–(11) provide the state-estimation foundation. The review states that combining (1)–(5) with (7)–(11) links optimization targets, battery-health constraints, and dispatch decisions in a unified AC-microgrid EMS framework.
- No numerical solution, convergence proof, or complexity analysis is given for these equations — "Not specified in paper".
