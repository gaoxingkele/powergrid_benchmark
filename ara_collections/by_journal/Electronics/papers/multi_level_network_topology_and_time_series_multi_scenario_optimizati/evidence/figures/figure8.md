## Visual description
- **Components**: The same 13-node network (Upper Grid at bus 1, PV/WT, diesel generator) shown at four increasing data-center DC-load penetration levels, each bus/line labeled AC or DC.
- **Panel (a) 0–40%**: Network is entirely AC — no DC retrofit is optimal below ~40% penetration (matches Table 3 Phase I).
- **Panel (b) 50–60%**: A limited set of buses/lines convert to DC (Table 3 Phase II: Bus6, line 5–6).
- **Panel (c) 70%**: More extensive DC conversion (Table 3 Phase III: Bus5/7/8; lines 1–5, 5–7, 5–8; new DC lines 4–7, 7–8).
- **Panel (d) 80%**: Nearly the whole network is DC except the grid-connection buses 1, 2, 3 (Table 3 Phase IV adds Bus9/10/13; lines 9–10, 10–13; new DC line 11–13).
- **What it conveys**: As DC-load penetration rises, the DC component of the optimal topology grows monotonically and orderly (staged retrofit), while the high-level grid-connection buses (1, 2, 3) and large-capacity AC generator buses stay AC because of high large-capacity converter cost.
