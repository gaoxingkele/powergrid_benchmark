## Visual description
- **Components**: The standard IEEE 33-node radial distribution feeder, source at node 0/1, main feeder nodes 1–17, laterals 18–21, 22–24, and 25–32. Five extra load points 33, 34, 35, 36, 37 are drawn above the main feeder as the new data-center load points to be connected.
- **Connections**: Radial trunk 1-2-...-17 with three branch laterals; the five added nodes are candidates to connect to one of the 32 non-balancing nodes via a single AC or DC line.
- **What it conveys**: The base test network for Section 5.2–5.4, modified so each load point carries a mix of AC and DC load (per Table 4) and five new data-center load points (total 600 kW + j320 kvar) are added.
