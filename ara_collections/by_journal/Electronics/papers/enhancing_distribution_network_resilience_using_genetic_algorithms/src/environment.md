# Environment

- **Language/runtime**: MATLAB R2025 (power flow + GA optimization). No source code released.
- **Framework**: DIgSILENT PowerFactory 2024 (power-flow / network modeling), coupled with MATLAB
  R2025 for the GA. (§4, p.8: "Power flow calculations and GA optimization were implemented in
  MATLABR2025 and PowerFactory 2024.")
- **Hardware**: Not specified in paper.
- **Data sources**: Self-contained synthetic test system defined in the paper — 6-bus radial feeder
  with line data (Table 1) and load data (Table 2). No external dataset; no data files released
  ("The original contributions presented in this study are included in the article," Data
  Availability Statement, p.12).
- **Key dependencies**: MATLAB R2025; PowerFactory 2024. Versions as stated; no dependency manifest,
  toolbox list, or GA library named.
- **Protocols**: GA optimization of a weighted multi-objective fitness (voltage profile + loss +
  resilience penalty) over DER setpoints / reconfiguration; steady-state evaluation (Tables 3–5,
  Figures 4–5) plus a single DER-trip contingency evaluation (Table 6). No preregistration.
- **Random seeds**: Not specified in paper. (GA initial population generated by a pseudo-random
  number generator; seed not reported — a reproducibility gap.)

## Note on code artifacts
The paper describes the method in prose plus a generic GA flowchart (Figure 2); it prints **no**
source code and **no** formal pseudocode block, and releases no repository. Per the ARA capture rules,
no `src/execution/` stub is created (the method already lives in `logic/solution/`). Concrete
hyperparameter values are captured as configuration in `src/configs/ga_optimization.md`.
