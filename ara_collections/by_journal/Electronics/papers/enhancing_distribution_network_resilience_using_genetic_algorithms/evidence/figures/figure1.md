## Visual description
- **Components (phases, left→right along the time axis)**: Normal Operation (functionality F0) →
  Disruptive event occurrence (arrow at t1) → System failure / degradation (drop to a degraded
  level F2 between t1–t2) → Partial recovery (rise starting t3) → State past partial recovery
  (plateau near F1 between t3–t4) → Full restoration (rise to t5) → Post-event normal operation
  (plateau back near F0).
- **Overlaid management bands (top row of labeled boxes)**: "Elimination of Disruptive Event" →
  "Maintaining Critical Functions" → "Quick Recovery and Restoration" → "Adaptation".
- **Axes**: Y = "Functionality of the Distribution System" (levels F0 > F1 > F2 marked); X = Time
  (event markers t1, t2, t3, t4, t5).
- **Connections / annotations**: Solid curve = system functionality trajectory; dashed curves =
  alternative (faster/slower) recovery trajectories. A grey down-arrow marks the disruptive-event
  onset. Shaded box marks the initial "Normal Operation" region.
- **What it conveys**: The trapezoidal (vs. triangular) model resolves the post-disturbance response
  into distinct degradation and recovery stages, separating Operational Resilience (onset →
  partial restoration) from Infrastructure Resilience (partial → full restoration). It is the
  conceptual frame the paper maps its optimized-vs-base results onto (shallower degradation, faster
  recovery).
- **Supports**: Frames concept "Trapezoidal resilience curve"; conceptual basis for the resilience
  objective (f3 penalty) and for interpreting C04/Table 6.
