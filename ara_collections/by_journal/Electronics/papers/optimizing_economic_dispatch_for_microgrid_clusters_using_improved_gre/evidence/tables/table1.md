# Table 1 - Definition of symbols in the power balance constraint equation for each MG

**Source**: Table 1, Section 2.2.1 in "Optimizing Economic Dispatch for Microgrid Clusters Using Improved Grey Wolf Optimization" (Electronics 2024, 13, 3139)
**Caption**: "Definition of symbols in the power balance constraint equation for each MG."
**Screenshot**: table1.png
**Location on page**: Page 4 (PDF page 4), upper-middle of page, directly beneath Figure 1.
**Extraction type**: raw_table

| Symbol | Definition |
| --- | --- |
| P_loadi(t) | Total load demand of the MG-i at time t. |
| P_WTi(t) | Wind turbine power output of the MG-i at time t. |
| P_PVi(t) | Photovoltaic power output of the MG-i at time t. |
| P_MTi(t) | Power output of the microturbine in the MG-i at time t. |
| P_DGi(t) | Power output of the diesel generator in the MG-i at time t. |
| P_ESSi(t) | Power output of the ESS in the MG-i at time t. |
| P_buyi(t) | Power purchased from the main grid by MG-i at time t. |
| P_selli(t) | Power sold to the main grid by MG-i at time t. |
| P_exi-j(t) | The power exchange between MG-i and MG-j at time t. |
