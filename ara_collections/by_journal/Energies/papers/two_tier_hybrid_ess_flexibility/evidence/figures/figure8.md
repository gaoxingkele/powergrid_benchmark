# Figure 8: Planning Result of COOT

**Source**: Page 21 of the original paper

**Description**: Daily scheduling scheme obtained by the COOT optimization algorithm for the HESS planning problem. The stacked histogram shows the output and input of all resources within a day, where:
- Positive values: resource output (generation)
- Negative values: resource input (consumption/storage charging)
- Different colors denote distinct resources (wind, PV, thermal, ESS charging/discharging, grid exchange)

This serves as a baseline comparison to evaluate IWAA's performance. The COOT-based scheme shows relatively higher interaction frequency with the main grid.
