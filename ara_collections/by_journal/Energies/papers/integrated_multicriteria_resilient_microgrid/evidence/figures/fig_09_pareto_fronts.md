# Figure 9: Pareto Fronts for All Simulation Cases

**Source**: Page 18 of the published PDF.

**Caption**: The Pareto front for the feasible and non-dominated solutions for all considered simulation cases (a-f).

**Content**: Six 3D scatter plots showing the Pareto fronts for each simulation case:
- **(a) Case 1**: Deterministic base case — no DRP, no forecasting, flat pricing
- **(b) Case 2**: Deterministic with TOU VP-CPP DRP
- **(c) Case 3**: Deterministic with SSAP VP-CPP DRP
- **(d) Case 4**: Stochastic planning (uncertainty only, no DRP/forecasting)
- **(e) Case 5**: Stochastic with LSTM forecasting and TOU VP-CPP DRP
- **(f) Case 6**: Stochastic with LSTM forecasting and SSAP VP-CPP DRP

Each Pareto front represents the set of non-dominated solutions in the 3D objective space (TLCC, DPSP, LPPP). The distribution and spread of points illustrate the trade-off characteristics for each planning approach.
