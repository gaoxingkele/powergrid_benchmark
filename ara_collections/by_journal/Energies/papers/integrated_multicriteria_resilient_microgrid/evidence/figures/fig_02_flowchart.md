1. Start with techno-economic parameters, weather data, electricity tariffs
2. Optimization initialization
3. MOPSO capacity sizing and operation strategy optimization

5. Uncertainty modeling using Monte Carlo
6. BESS state evaluation (charge vs discharge)
7. DRP activation logic (surplus vs shortage conditions)
8. Critical vs non-critical state determination
9. Multi-criteria ranking and selection using TOPSIS
10. Best planning scheme output
