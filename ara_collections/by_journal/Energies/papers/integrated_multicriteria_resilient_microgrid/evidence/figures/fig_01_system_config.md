# Figure 1: Proposed System Configuration

**Source**: Page 4 of the published PDF.

**Caption**: Proposed VRE-based community microgrid system configuration showing WT (wind park), PV (photovoltaic system), BESS (energy storage system), and flexible demand resources, all connected through the microgrid dispatch and control center via control and communication networks.

**Content**: Schematic diagram illustrating the microgrid architecture with the following components:
- Wind park (WT)
- Photovoltaic system (PV)
- Battery energy storage system (BESS)
- Flexible demand resources
- Critical loads
- Microgrid dispatch and control center
- LSTM forecaster (input: weather, VRE generation, load demand; output: state of charge)
- Control and communication network
- Microgrid distribution infrastructure (AC)
