# table_06

## Description
Table 6. Cost and economic performance metrics under different scenarios (power price, sellback rate, expected inflation) for G/PV.

## Source
Page 18-19 of the original PDF.

## Extracted Data
See PDF pages 18-19 for the full table. Key findings: Shortest payback period = 2.1 years at 0.16 USD/kWh power price, 0.18 USD/kWh sellback, 5% inflation, achieving IRR = 47%. At 30% inflation, payback exceeds 25 years and IRR becomes uncertain (system remains in debt).

## Notes
- Data values are as reported in the original paper.
- NPC = Net Present Cost; LCOE = Levelized Cost of Energy; IRR = Internal Rate of Return.
- G = Grid; PV = Photovoltaic; WT = Wind Turbine; Gen = Diesel Generator; B = Battery.
