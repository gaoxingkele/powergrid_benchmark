- **Axes**: Time (horizontal, linear scale), Wind Speed (vertical, linear scale)
- **Trend summary**: Three representative typhoon wind-speed scenarios (Scenario 1, 2, 3) shown as time-series curves, each representing a different disaster intensity profile over the simulation horizon. Scenarios differ in peak wind speed, onset time, and duration. The wind speed data serve as input to the failure probability calculation in Equation (5).
- **Key insight**: The three scenarios represent different intensity levels of typhoon events. The scenario probabilities are initially estimated from historical data and then allowed to vary within the l1/l-infinity-norm ambiguity set in the DRO formulation.
