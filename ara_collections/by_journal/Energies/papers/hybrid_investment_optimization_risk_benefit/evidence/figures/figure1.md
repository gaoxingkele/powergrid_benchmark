**Description:** The research framework of the two-stage PGI optimization model. Stage 1 involves constructing risk and benefit indicator systems, calculating indicator weights via Bayesian BWM, and comprehensive evaluation via TOPSIS. Stage 2 involves objective function construction (benefit per unit risk), constraint setting (investment amount, power demand, low-carbon), and model solving via ILA to produce PGI plans.

**Visual description:** Flowchart showing two stages. Stage 1: Construction of risk/benefit indicator systems -> Calculation of indicator weights via Bayesian BWM -> Comprehensive evaluation via TOPSIS -> Evaluation results. Stage 2: Objective function construction and constraints setting -> Model solving via ILA -> PGI plans.
