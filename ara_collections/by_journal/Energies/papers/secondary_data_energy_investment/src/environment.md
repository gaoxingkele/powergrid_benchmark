# Reproducibility Environment

## Software

- **Microsoft Excel for Microsoft 365** for data compilation, cleaning, normalization, descriptive analysis, weighting calculations, ranking procedures, correlation analysis, sensitivity checks, and visualization
- **Python 3.11** for additional data processing, statistical calculation, robustness testing, and figure generation
- **Python packages**: pandas, NumPy 2.5.0, SciPy 1.18.0, scikit-learn 1.9, Matplotlib 3.11.0

## Data Sources

| Dataset | Source | Indicators Accessed |
|---------|--------|-------------------|
| World Development Indicators (WDI) | World Bank | GDP per capita, GDP growth, inflation, FDI inflows, energy import dependence, CO2 per capita |
| Worldwide Governance Indicators (WGI) | World Bank | Regulatory quality, government effectiveness |
| Energy Data | Our World in Data (OWID) | Fossil electricity share, renewable electricity share, electricity carbon intensity, electricity demand, renewable installed capacity |
| Yearly Electricity Data | Ember | Supplementary electricity generation and carbon intensity data |
| Renewable Energy Statistics | IRENA | Renewable installed capacity |
| POWER Data Access Viewer | NASA | Solar irradiance, wind speed at 50m |
| Energy Database | Eurostat | Electricity price data |
| Transparency Platform | ENTSO-E | European electricity price data |
| Country-level economic data | Countryeconomy | Supplementary electricity consumption and generation values |

## Sample

- 36 countries: EU-27 member states, United Kingdom, Norway, Switzerland, Turkiye, United States, Canada, Japan, South Korea, Australia
- 18 criteria (C01-C18) organized in 6 dimensions
- Latest available data (primarily 2024-2025, varying by indicator)
