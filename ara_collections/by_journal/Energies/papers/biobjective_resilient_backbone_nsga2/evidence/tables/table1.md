# Table 1: Comparison of irace Candidate Parameter Configurations

## Source
Section 6.2, Page 14

## Content
Comparison of four candidate parameter configurations (Baseline, Candidate A, B, C) for the stage-related parameters of TER-NSGA-II, tuned using irace. Metrics include normalized ratios p1=T1/G, p2=T2/G, pr=Treverse/G, mean cost, standard deviation, feasible count, and zero-cost frequency.

## Key Values
- Candidate C selected as final configuration
- p1=0.387, p2=0.577, pr=0.247
- Corresponds to T1=77, T2=115, Treverse=49 for G=200
- Selected for highest feasible count, zero zero-cost frequency, and best overall balance
