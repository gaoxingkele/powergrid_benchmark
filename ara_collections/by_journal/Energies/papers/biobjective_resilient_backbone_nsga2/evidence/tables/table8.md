# Table 8: Computational Performance Comparison

## Source
Section 6.7, Page 20

## Content
Comparison of average runtime and feasible-solution count for all algorithms on both IEEE 118-bus and IEEE 300-bus systems.

## Key Values
| System | Algorithm | Runtime (s) | Feasible-Solution Count |
|--------|-----------|-------------|------------------------|
| IEEE 118-bus | TER-NSGA-II | 1336.49 +/- 99.93 | 24.42 +/- 8.70 |
| IEEE 118-bus | NSGA-II | 254.35 +/- 38.60 | 22.00 +/- 25.07 |
| IEEE 118-bus | NSGA-III/NG | 219.26 +/- 94.29 | 3.66 +/- 1.56 |
| IEEE 300-bus | TER-NSGA-II | 814.62 +/- 129.84 | 50.00 +/- 0.00 |
| IEEE 300-bus | NSGA-II | 437.71 +/- 49.94 | 50.00 +/- 0.00 |
| IEEE 300-bus | NSGA-III/NG | 631.00 +/- 83.76 | 1.60 +/- 0.52 |

TER-NSGA-II incurs higher computational cost in exchange for better feasible-domain search and higher-quality solution sets.
