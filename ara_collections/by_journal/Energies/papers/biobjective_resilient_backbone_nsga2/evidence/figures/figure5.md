# Figure 5: Topological Configurations of Backbone-Grid Schemes

## Source
Section 6.5, Page 18

## Content
Three subfigures showing the topological configurations of selected backbone-grid schemes from the Pareto optimal set:
- (a) Economic-oriented: Minimal configuration of 54 transmission lines, compact structure satisfying basic backbone connectivity
- (b) Transitional scheme: 67 lines, balancing economic efficiency with enhanced critical region support
- (c) Resilience-oriented: 70 lines, strengthened critical corridors and network redundancy, achieving lowest F2 value
