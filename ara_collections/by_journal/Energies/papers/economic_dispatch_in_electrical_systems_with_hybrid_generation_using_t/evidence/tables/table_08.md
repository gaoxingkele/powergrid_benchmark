Table 8. Coefficients of each thermoelectric for fuel costs.

## Description
A table listing the fuel cost coefficients for five thermoelectric units, including: ai, bi, ci (quadratic cost coefficients), ei and fi (valve-point effect coefficients). These coefficients define the individual cost functions for each thermal generation unit used in the economic dispatch optimization.
