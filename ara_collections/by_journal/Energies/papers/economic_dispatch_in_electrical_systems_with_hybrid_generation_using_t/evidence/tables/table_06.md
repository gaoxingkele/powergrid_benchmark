## Caption
Table 6. Penalty factors used for constraint violations in each optimization algorithm. pen1 corresponds to the power balance constraint, and pen2 corresponds to the water balance constraint in hydroelectric reservoirs.

## Page
11

## Description
A table listing the penalty factors for each optimization algorithm: pen1 (power balance constraint) values are 20 for PSO, 30 for GWO, 20 for DE, and 20 for CA; pen2 (water balance constraint) values are 360 for all algorithms. These penalty factors are used to enforce constraint satisfaction within the objective function.
