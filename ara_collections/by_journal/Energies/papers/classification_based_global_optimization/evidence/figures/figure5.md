## Visual description
- **Components**: Single-line diagram of IEEE 33-bus radial distribution network showing all 33 buses numbered 1 through 33, with 32 distribution branches connecting them in a radial tree topology.
- **Connections**: Substation at bus 1 (root). Main feeder branches at bus 2 towards bus 22, and at bus 3 towards bus 25, with further sub-branches. Bus numbers are labeled. Branch impedances are shown along each connection.
- **Annotations**: The network topology follows the standard IEEE 33-bus test system configuration. Node numbering and branch configuration are shown.
- **What it conveys**: The radial, unbalanced structure of the 33-bus test network used for validation. The longest feeders (buses 1-18 and branching paths) are where voltage drops are most significant.
