## Visual description
- **Components**: The framework diagram shows a three-column structure:
  - Left column (Input): IES operational parameters including CHP limits, GB limits, WHU efficiency, ESS capacity, tiered pricing parameters, renewable generation profiles, and load demand profiles
  - Middle column (Optimization Algorithms): Five algorithm blocks — IGA (highlighted as proposed), MGA, MPSO, SGA, MABC
  - Right column (Evaluation): Three key metrics — Constraint violation (V), Operating cost (o1), Carbon emissions (o2)
- **Flow**: IES parameters flow into all five algorithms. Each algorithm produces optimized scheduling results. The results are evaluated on the three metrics to compare performance.
- **What it conveys**: The case study evaluates IGA against four baseline algorithms (MGA, MPSO, SGA, MABC) using the same IES operational parameters, with comparative analysis based on constraint violation, operating cost, and carbon emissions.
