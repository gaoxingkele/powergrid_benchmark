# Related Work

The paper situates its contribution within the following existing research streams:

## 1. Multi-Objective Scheduling and Configuration of Distribution Networks
- Reference [7] proposed a hierarchical EV charging scheduling strategy based on NSGA-II, reducing user costs while improving system balance.
- Reference [8] used improved PSO for multi-objective collaborative optimization of active distribution networks, showing advantages in voltage stability and load peak reduction.
- Reference [9] introduced distributed robust optimization into multi-objective planning, reducing uncertainty risk and improving economic efficiency.

## 2. Energy Storage and Multi-Energy Coupling
- Reference [10] studied ES capacity optimization in microgrids with CHP and EV scheduling, demonstrating multi-energy coupling benefits.
- Reference [13] used NSGA-II for ES site selection and capacity configuration in active distribution networks, validating intelligent algorithms for non-convex multi-objective problems.
- Reference [14] proposed a safe energy policy optimization method for multi-energy microgrid control addressing wind/solar uncertainty.

## 3. EV Impact on Distribution Networks
- Reference [11] analyzed EV access mode impact on static voltage stability margin, finding that different access methods affect system load absorption capacity.
- Reference [12] reviewed multi-objective optimization of multi-energy systems and EV charging stations, noting deficiencies in user behavior modeling and grid-transportation coupling.

## 4. Multi-Objective Evolutionary Algorithms
- Reference [16] (Jensen, 2003) systematically analyzed computational complexity of NSGA-II and other multi-objective evolutionary algorithms, providing foundation for algorithm selection in power system optimization.

## Gap Identified
Existing research has achieved considerable results but most results remain at simulation level, lacking verification in actual engineering scenarios. This paper aims to improve operational efficiency through coordinated optimization of ES, EV, and DG, validated on IEEE 33-bus system with engineering verification from a regional grid renovation project.
