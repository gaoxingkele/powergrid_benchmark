# Figure 1: Integrated Grid Planning Framework Based on Generalized Adequacy

**Source:** Page 10, Section 3.1, Yin et al. 2025.
**Caption:** "Schematic diagram of the integrated grid planning framework based on generalized adequacy."

## Type: Diagram

## Visual Description

A flow diagram showing the iterative planning process:

1. **Input:** Historical data curve clustering is used to identify representative planning scenarios.
2. **Planning Model (Section 3.2):** The integrated power grid planning model takes the representative scenarios and produces optimal planning schemes for multi-type resources and the power grid.
3. **Generalized Adequacy Evaluation (Section 2.2):** Each planning scheme is evaluated against the seven generalized adequacy indicators.
4. **Decision Point:** The framework checks whether generalized adequacy criteria are met.
   - If **No** (inadequate): Identify extreme scenarios where adequacy indices exceed predefined limits. These critical scenarios are fed back into the planning model scenario set, and the process iterates.
   - If **Yes** (adequate): The scheme becomes the final planning output.
5. **Output:** Final planning scheme that satisfies generalized adequacy requirements.

The diagram illustrates a closed-loop feedback process, not a single-pass optimization.
