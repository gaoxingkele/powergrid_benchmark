# Table 7

**Caption:** Types of planning variables.

**Page:** 10

**Description:** Table classifying OPF planning variables into binary and continuous types. Binary variables include installation of new secondary substations, upgrade of secondary substation capacity, installation of new ESS, installation of PV systems, installation of controlled EVCS, installation of parallel feeders, upgrade of feeder capacity. Continuous variables include battery state of charge, substation power injection, voltage magnitude, voltage angle, branch power flow, generation power injection, load shedding.
