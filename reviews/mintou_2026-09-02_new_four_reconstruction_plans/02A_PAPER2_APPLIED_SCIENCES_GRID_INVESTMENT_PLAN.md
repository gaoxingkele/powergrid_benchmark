## 1. 当前证据与不可越界项

现有实验使用 120 个候选项目、8 个场景、30 个共同随机种子和每次 3,200 次精确评价。现有冻结汇总中，BiLo-NSGA 的 pooled HV 为 0.16277，NSGA-II 为 0.17213，PLS 为 0.11626；BiLo 对 NSGA-II 的四个主要对比中没有胜场并出现四个失利。局部搜索参数 `(2,2)` 比 `(8,4)` 联合干预高 4.29%，但 NoBackward 和 LegacyDeletion 的均值更高，因此不能把“完整双向机制优越”写成既定结论。

以下边界立即锁定：

- 不隐藏 BiLo 相对 NSGA-II 的现有负结果。
- 不把一般项目组合改名为网络安全投资，不把 PG-T13 当作当前必需数据。
- 不把删除后再添加的两步过程声称为已实现的原子 substitution。
- 不把代理收益、代理风险或归一化得分写成真实投资回报、可靠性提升或工程部署收益。
- 不从单一合成任务族推断算法普遍优越。

## 2. 重构后的研究问题

- **RQ1：** 在等评价预算和一致约束处理下，非支配排序与双向局部搜索能否改善电网投资候选集的质量、可行性和决策覆盖？
- **RQ2：** 前向添加、后向删除以及二者组合各自贡献什么，是否存在稳定交互？
- **RQ3：** 结论能否跨至少两个相互独立的投资任务族、预算水平和规模保持？
- **RQ4：** 在使用可追溯成本和至少一层物理或外部验证时，代理 Pareto 排名与工程价值是否一致？
- **RQ5：** 哪些条件下双向搜索无收益或产生额外计算代价？

中心叙事不是预设“双向搜索更好”，而是识别非支配排序与双向局部搜索在受预算约束投资优化中的增益、失败条件和工程边界。

## 3. 方法重构

### 3.1 操作定义

- **Non-dominated sorting：** 明确等级、拥挤度/多样性和精英保留的角色。
- **Forward local search：** 在剩余预算和约束允许时添加一个候选项目。
- **Backward local search：** 删除一个低边际贡献或导致约束压力的已选项目。
- **Bidirectional search：** 允许前向和后向移动，但只有代码真正一次性评价“删一加一”时才称 atomic substitution。
- **Repair：** 与局部搜索分离；修复只恢复可行性，不能被计入方法增益。

### 3.2 必做正交消融

| NDS | Forward | Backward | 配置 | 目的 |
|---|---|---|---|---|
| 是 | 否 | 否 | NDS-only | 非支配排序控制组 |
| 是 | 是 | 否 | Forward-only | 识别添加移动 |
| 是 | 否 | 是 | Backward-only | 识别删除移动 |
| 是 | 是 | 是 | Bidirectional | 识别组合与交互 |

Repair、初始化、种群规模、终止预算和评价缓存必须一致。现有 NoBackward、LegacyDeletion 等结果进入旧任务族诊断，不能替代冻结后的正交设计。

## 4. 实验重构

### 4.1 新命名空间

`paper_projects/mintou_p6_bilonsga_project_review/experiments/p6_s4_applsci_grid_investment_v1/`

旧的 `p6_s3_matched_effort` 只读，不覆盖输出。

### 4.2 两个独立任务族

1. **现有代理项目组合族：** 保留 120 项目和 8 场景，用于与历史结论连续比较。
2. **电网动作对齐族：** 由公开网络中的线路/变压器升级、储能或 DER 候选动作构成；每个动作需要成本、容量变化和评价路径。若无法建立真实动作，明确称“校准案例”，不称真实工程部署。

两个任务族应在数据生成机制、约束或动作语义上独立，不能仅更换随机种子。

### 4.3 基线与公平性

- NSGA-II；
- 至少一个分解型 MOEA（例如现有 MOEA/D 实现，需核验配置）；
- PLS；
- 一个简单工程排序/贪心基线；
- 小规模实例上的精确或 epsilon-constraint 参照（若计算可行）。

所有随机方法采用共同种子和相同精确评价预算。报告实际唯一评价次数、重复候选比例、可行率、运行时间和失败运行。

### 4.4 指标与统计

- 主指标：预先锁定参考集/参考点的 HV 和 IGD+；
- 决策指标：可行率、预算利用率、组合覆盖/稳定性、代表性膝点的成本—收益—风险；
- 计算指标：墙钟时间、唯一评价次数、局部搜索开销；
- 统计单位：场景内共同种子的配对结果，不能把前沿点或时间步当独立样本；
- 同一比较族报告效应量、置信区间、原始与多重校正后检验。

### 4.5 工程验证门禁

优先级依次为：

1. 真实或官方可追溯的成本/容量数据；
2. 至少一个公开网络上的潮流、损耗、电压或容量约束复核；
3. 有记录的专家/历史方案外部比较；
4. 若以上均不可得，仅保留代理筛选结论。
