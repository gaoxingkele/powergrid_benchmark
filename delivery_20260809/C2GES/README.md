# C2GES Applied Sciences Submission Package

Prepared on 2026-08-08.

Contents:

- `final_pdf/`: the current compiled manuscript PDF;
- `latex_source/`: the complete MDPI LaTeX source, class files, bibliography,
  figures, generated tables, and verification scripts;
- `verification_data/`: hash-bound five-seed, ablation, MiniLM/BGE, crossed
  5-by-5, conversion-audit, and NERC machine-silver records supporting the
  submission-version claims; and
- `SHA256SUMS.csv`: file sizes and SHA-256 hashes for the entire package.

The public project repository is <https://github.com/gaoxingkele/c2ges>.
Downloaded NERC PDFs, other third-party source documents, model weights, API
credentials, and environment files are not distributed in this package. Access
to restricted source materials is subject to third-party permission and the
applicable licenses. NERC labels included here are machine-adjudicated silver,
not human or domain-expert ground truth.

The corresponding author is Yang Yong. The correspondence email in the
manuscript must be filled manually before journal submission.
