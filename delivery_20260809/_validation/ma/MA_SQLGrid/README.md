# MA-SQLGrid Applied Sciences Submission Package

Prepared on 2026-08-08.

Contents:

- `final_pdf/`: the current compiled manuscript PDF;
- `latex_source/`: the complete MDPI LaTeX source, class files, bibliography,
  figures, tables, and verification scripts;
- `verification_data/`: hash-bound result tables, prediction ledgers, run
  manifests, audits, and machine-silver annotation records supporting the
  submission-version claims; and
- `SHA256SUMS.csv`: file sizes and SHA-256 hashes for the entire package.

The public project repository is <https://github.com/gaoxingkele/ma-sqlgrid>.
Downloaded third-party databases, model weights, API credentials, environment
files, and excluded incident runs are not distributed in this package. Access
to restricted source materials is subject to third-party permission and the
applicable licenses.

The corresponding author is Yang Yong. The correspondence email in the
manuscript must be filled manually before journal submission.
