# 从设计到正式蒸馏的执行与验收

## A：本轮已实现的基础设施

专用目录、实体关系模式、字段字典、三级分类树、期刊扩展、难度/质量分离规则、可追溯 observation 协议、只读本地 PDF 盘点与自动候选抽取、JSON/SQLite/HTML 输出、skill 消费接口及单元测试。实际执行统计见 outputs/RUN_REPORT.md。

## B：人工校准与解析升级

1. 在候选池中，按 Applied Sciences / Energies / Electronics / IEEE Access 与预测/规划/调度分层选文章；每主期刊先选 3–5 篇结构差异大的样本作为解析校准，不作为平均期刊水平。
2. MDPI 有合法结构化 XML/HTML 时优先使用；否则按字号、坐标、缩进、两栏和跨页修复段落及标题。记录每个修复的版本。
3. 完整阅读全文的标注者逐项核对公式编号/类型、章节、段落、图表与消融；输出对象级定位。用另一名独立标注者复核核心计数与语义标签，不能把两个 LLM 的意见称为双人人工标注。
4. 记录计数绝对误差、precision/recall、边界 F1、角色一致率与分类混淆；难度维度检查加权 kappa/ICC 的适用条件，报告分歧而不只输出仲裁后的数字。
5. 验收采用研究内目标：关键编号图表对象无漏记/重复；公式组数抽样误差≤5%；段落边界 F1≥0.90；语义标签一致性达事前约定且误差分析可解释。未通过就保持 candidate，不升级状态。目标不是期刊要求。

## C：规模化语义蒸馏

冻结抽样框与年份，建议每主期刊先做到 20–30 篇**相关且经核验**研究论文；每种任务不足则保留稀疏层，不强行补成一个总均值。其他 MDPI 期刊有足够相关文章再启用，不因为目录中有 10 篇 PDF 就认定能得到期刊画像。

逐篇完成：章节/段落动作、公式与算法三级类型、实验设计与统计前提、图表证据作用、理论使用深度、框架数据流、结论映射、语言功能。LLM 如用于候选标签，记录模型版本/prompt/hash/温度/来源窗口，并单独审核；启用外部全文上传须另行确认数据范围和服务方。

## D：画像冻结与评审接入

建立 corpus cohort manifest → 所有字段缺失率 → 文章等权分布 → 分层置信区间 → difficulty / quality 分离画像 → 典型/边界/失败案例。确认来源 DOI、版本与撤稿/更正状态。用至少一篇留出的文章测试检索和画像稳定性，禁止用目标稿件反向调分布。

与现有 Paper_CCF/ARS/paper harness 接口对接时只传 evidence-backed profile；官方要求、样本统计、研究者建议三种 provenance 不得混合。若要替换旧蒸馏数据，先保留版本和来源映射，不能覆盖旧 JSON 以抹去口径变化。

## 最终交付门

- 单篇宽表中的每个 verified 值均能追到源对象。
- 每个段落、公式、实验、图表均有独立实体和唯一 ID；同一对象不因多处引用重复计数。
- 对照表覆盖用户提出的所有字段；空值有状态，统计分母明确。
- 难度评分有证据、有双评/分歧记录，不用文章长度替代理论强度。
- 样本平均值具有明确人群、年份、任务、n、缺失率和版本，不称为录用水平保证。
- JSON schema、外键/对象映射、重复 DOI、计数与子实体一致性、未知字段、来源链接均通过测试。
- 跨期刊、跨会议迁移只增加 profile/taxonomy extension，不改现有通用字段语义。
