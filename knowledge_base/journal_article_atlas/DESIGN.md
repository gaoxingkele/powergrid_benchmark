# 解构元模式与测量协议 v0.1

状态：可执行设计＋自动候选实测；尚未完成正式语料校准。

## 1. 采样与身份层

分析单位首先是**文章版本**，不是一个 PDF 文件名。保存 DOI、题目、期刊、出版商、文献类型、年份、special issue、公开状态、撤稿/更正核查状态、来源 URL、原件路径、内容哈希、全文类型及解析器版本。相同哈希只算一份；相同 DOI 不同文件保留版本链，人工选择 version of record，不把预印本和正式版当两篇。

本地下载是便利样本，不是期刊随机抽样。先列候选池，记录纳入理由、排除原因与选样日期。按期刊 × 任务（预测/规划/调度/诊断/信息系统）× 文献类型（方法/应用案例/综述/数据或软件）× 年份分层。综述不与研究论文共同计算实验数；理论论文没有训练集不记为缺陷。

电力相关性分为 direct（电网/电力任务）、adjacent（可迁移的信息/优化方法）、out-of-scope、uncertain。第一轮标题关键词只产生 relevance_candidate，必须由摘要/任务定义复核；不把 Machines 中所有机器人论文或 Information 中所有 NLP 论文算成电力论文。

## 2. 关系模型：总表背后的子表

| 实体 | 粒度 | 关键关系 |
|---|---|---|
| paper / source | 一篇版本 / 一个源文件 | version_of、corrects、derived_from |
| section | 每个一级、二级、三级章节 | part_of、prepares、depends_on、answers |
| paragraph | 每个语义段落，多页可对应多个定位 | motivates、contrasts、defines、qualifies、transitions_to |
| equation | 每个独立数学陈述/编号组 | defines、constrains、derives_from、implements |
| algorithm / framework | 每个模块与整体流程 | consumes、produces、calls、optimizes |
| claim / theory | 每个可检验主张及所用理论 | supported_by、assumes、generalizes、contradicts |
| experiment / contrast | 独立研究问题设计 / 受控差异 | tests、ablates、compares、replicates |
| dataset / statistical_analysis | 数据版本、分析单位、估计量 | evaluates_on、clusters_by、estimates |
| table / figure | 编号对象，panel 为子实体 | visualizes、supports、duplicates |
| lexical_pattern | 术语、搭配、抽象句式 | used_for、occurs_in、qualified_by |
| cohort / profile | 可比样本集合 / 统计画像 | includes、aggregates、calibrated_by |

字段值使用 observation：`entity_id, field_id, value, status, evidence[], method, annotator, confidence, version`。证据定位至少包含源哈希、物理页码（从 1 开始）、可选印刷页码、bbox/章节/段落/对象标签；数值的分母和统计范围不能省略。同一个字段的冲突观测并存，不覆盖原判定。

状态枚举：verified、automatic_candidate、not_reported、not_applicable、extraction_failed、uncertain、not_assessed。只有核查了应出现该信息的位置才能填写 not_reported；没有检查是 not_assessed；计数 0 必须表示确实检查过且不存在。解析失败不是 0。

## 3. 数量统计的硬口径

### 3.1 公式

分别保存：编号 display groups、无编号 display groups、inline math、独立数学陈述、附录公式、定理/引理/证明数量。多行 align 共用一个编号算一个编号组；(3a–3d) 保存一个父组与四个子项，报告时明确哪个口径。绝不以最大编号或正文引用次数代替公式数量。

公式类型三级词表见 taxonomy：物理→潮流→AC/DC；优化→目标/约束→单目标/多目标、整数/连续、预算/安全约束；学习→架构/训练→注意力/损失；统计→估计/推断→估计量/区间/检验；算法→更新/复杂度→迭代更新/界。允许多标签并指定 primary_type，类型数之和不强制等于公式总数。

每式还记录功能（定义、建模、推导、判据、实现、评价）、来源（新推导/改写/标准引用）、假设、符号首次定义、量纲、实现映射、是否被实验直接检验。公式多不能自动推断理论深度。

### 3.2 框架与算法

三级路径：任务范式 → 方法家族 → 具体机制。另设独立组合轴：单模型/串联流水线/并联集成/嵌套优化/双层决策/闭环/多智能体。记录输入输出、模块边界、训练与推断区别、决策变量、约束处理、复杂度、收敛条件、可复用标准组件和论文新增组件。不要把“CNN+LSTM+attention”三个名字自动算三项创新。

### 3.3 段落与章节

默认正文范围为 Introduction 开始至 Conclusions 结束，排除摘要、作者信息、参考文献、图表题注、独立公式、伪代码、声明和附录；各部分另计。章节保持 parent_id 与 level，分别统计一级章节数和所有层级标题数。

英文 word 使用声明的 tokenizer；中文另用字数/分词，不能混算。段落同时存 mean/median/p10/p90 words、句数、长度占比、主次作用。PDF text block 仅为候选段落；跨页段落重组且保留多个 source spans。段落作用：背景、问题、缺口、研究目标、贡献、定义、假设、推导、算法解释、实验设置、结果描述、对比解释、机制解释、局限、意义、未来工作、衔接。

章节逻辑用“输入承诺→完成的论证任务→输出给下一节的信息”记录。跨章节采用有证据的有向边：Introduction 的 C1 应连到 Methods 的 M1、Results 的 E1、Discussion 的边界 L1、Conclusion 的结论 K1。未闭环主张、方法无实验、结论新增主张、重复图表是缺口，不是可效仿模式。

### 3.4 实验、消融与统计

**实验数量**按独立研究问题与设计计；数据集数、场景数、方法数、预算数、随机种子数、运行调用数、统计比较数分别计。一个 5 方法 × 3 数据集 × 10 种子矩阵不算 150 个独立实验。

消融严格拆分：受控组件消融、因子实验、机制替代、超参数敏感性、鲁棒性、跨域泛化、可视化案例。Full vs no-path 只有其他设置匹配时才是受控消融。记录每一变体改变了哪些因素、是否重新调参、匹配的是参数数/算力/评估次数/输出预算，以及参照组和混杂。

统计特性与统计理论分开：数据形态（时间依赖、层级、偏态、重尾、缺失、不平衡）→假设（独立、配对、交换性、平稳性等）→估计量→检验/模型→区间/效应量→多重比较→稳健性。区分作者报告、我们的重算和我们的判断。关键词命中 bootstrap 不能说明 bootstrap 用得正确；不显著不等于等效，预测改进不等于因果效果。

记录独立分析单位及其 n，而不只训练样本条数；时间序列 split、泄漏、滚动原点、跨站点/跨系列外测、功效或精度论证、随机种子、失败运行、异常排除、选择偏差都设独立字段。

### 3.5 图表、结论和语言

图按独立编号计，panel 另计；图例项、正文引用和 PDF 内嵌图片资源数都不是插图数。表题连续页的 continued 不重复计。表内容需要结构化列：对象、比较维度、指标、单位、n、均值/离散性、基线、统计标记、最佳值规则、支持哪个主张。

图类型：问题场景、系统拓扑、流程框图、模型架构、算法流程、时序、散点、分布、箱/小提琴、误差棒/森林、收敛、Pareto 前沿、热图、消融、交互、地图、设备照片、概念图。视觉美观与证据作用分开评。

Conclusions 分解为：回答哪个 RQ、核心发现、数值和估计条件、机制解释、适用边界、负结果、局限、工程含义、未来工作；核对每句话是否已有 Methods/Results 支持。不是把“future work”一词出现就判定局限充分。

语言保存 lemma、领域术语、多词搭配、词性/语态/时态、hedging、causal-strength、过渡功能、句长分布、术语一致性、nominalization、主题推进。频率优先使用文档频率和每千词标准化，正文与参考文献隔离。不用常见套话的频率给科学质量加分。

句式库存结构化槽位，如“Under [condition], [method] changed [metric] by [effect], relative to [comparator].”；这是自行概括的功能句式，不是原句复制。原句若保留，注明许可和来源，控制摘录长度；禁止拼接大段原文供“仿写”。本地全文解析缓存不作为公开数据发布。

## 4. 难度画像与文章水平必须分开

保存六维 D 向量，每维 0–4；not_applicable 或 not_assessed 用 null，不填 0：

| 维度 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 理论 D_T | 无新增理论任务 | 标准式直接应用 | 条件推导或模型改写 | 非平凡证明/严谨推导 | 多个相互依赖结果与清晰适用边界 |
| 算法 D_A | 无算法任务 | 单标准模块 | 多模块可复现组合 | 耦合/嵌套与复杂度分析 | 非平凡算法设计且实现约束明确 |
| 统计 D_S | 无推断任务 | 描述统计 | 明确配对或重复设计 | 层级/依赖/多重性处理 | 复杂识别或推断且验证假设 |
| 数据 D_D | 无数据任务 | 单公开标准集 | 多源预处理/标注 | 跨域外测或高成本采集 | 多场景真实采集、治理与独立验证 |
| 工程 D_E | 无系统实现任务 | 离线仿真 | 物理约束/多系统耦合 | HIL/现场接口/实时验证 | 多现场或长期系统级验证 |
| 跨学科 D_X | 单领域任务 | 借用术语/工具 | 两域接口明确 | 多域假设与变量实质耦合 | 耦合理论被独立验证且限制明确 |

这是**本研究提出的工作量/技术要求锚点**，不是领域官方等级，更不是“越难越好”。评分必须附证据与解释、评审者和不确定区间。0 的描述仅表示无该任务；不适用研究设计仍应选择 NA，而非以 0 惩罚。主报告向量，不默认压成总分。

可选复合分 `D = 25 * sum(w_j d_j)`，仅同适用维度、完整经核验记录、固定任务类权重且权重总和 1 时计算；不跨不同维度覆盖率比较。权重与锚点要版本化，做扰动敏感性。当前版本不自动计算 D，不凭公式/图数或算法名称赋分。

**质量 Q**另存：论证有效性、证据强度、比较公平性、统计适当性、可复现性、叙事清晰度、贡献边界，各自评分与理由。低难度可以高质量，高难度可以失败。最终审稿仍以核心错误/范围不符等硬问题为优先，不能被高数量抵消。

## 5. 期刊“平均水平”的保存方法

保存的是 `observed_published_sample_profile`，从来不是 `acceptance_threshold`。同行评审已录用样本缺少被拒稿分母，不能估计录用概率或接收边界。

每个字段报告 n_total、n_applicable、n_verified、missing_by_status、mean、median、SD、IQR、p10/p90、最小最大、单位和抽样定义；百分比以明确分母计算。先逐篇计算长度等指标，再文章等权聚合，不让长文的段落淹没短文。

自动候选统计与 verified 统计分表。数值可用经验分布/分位数；类别用比例与多标签共现；难度用向量分布；逻辑用 RQ→方法→实验→结论闭环率；叙事用动作转移矩阵；用词按 paper-level DF/标准化频率，句式按功能与章节分层。

只有可比层内足够独立文章且校准通过才发布稳定画像。第一版研究内规则：n_verified<10 只展示个案；10–19 标为 small-sample；≥20 才允许 provisional reference profile，仍须报告来源偏差与区间。不是数学定理或期刊规则。来自同一专题/作者群时按相关单元聚类或报告敏感性，不假装完全独立。

正式区间采用预声明的文章级/相关单元级 bootstrap 或合适的类别区间，记录 seed、次数与估计量；小样本不制造伪精确区间。每次画像绑定 corpus manifest SHA、版本、提取与人工标注版本，不静默回填旧画像。

## 6. 对 skill 的使用方式

输入：目标期刊、研究类型、任务、可选年份、待评稿件和用户关心的维度。输出：最近邻可比文章＋位置明确的差距，而非“还差 6 个公式”。

评审：硬错误→证据完整度→科学与工程边界→可比画像→语言建议。写作：选取承担相同论证功能的范式，自行表达，并用当前真实结果填槽；不复制原作的创新、结论或因果语气。采用负结果论文时保留其边界，不能为了模仿平均正向叙事粉饰结果。

## 7. 来源边界

2026-09-13 检索的一手页面：

- [MDPI article types](https://www.mdpi.com/about/article_types)：不同文献类型具有不同结构；不是所有期刊接收所有类型。
- [Energies scope](https://www.mdpi.com/journal/energies/about)：覆盖能源科学、技术、政策和管理，说明只按期刊名混算任务并不合适。
- [IEEE Access reproducibility](https://ieeeaccess.ieee.org/authors/reproducibility/)：方法说明、数据与代码是复现的重要材料。

这些页面支持文献类型与复现字段的设置，**不支持本库的数量阈值、难度评分或录用概率**。MDPI 部分作者指南直连返回 429，未将无法读取页面的内容记为已核验；期刊扩展中的优先字段是本研究设计，后续按实测修订。
