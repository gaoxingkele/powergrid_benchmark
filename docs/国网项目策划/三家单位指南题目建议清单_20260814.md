# 第〇部分：三家单位调查画像（2026-08 网络调查）

## 湖北电科院——光明大模型应用先锋 + 高比例新能源大省

- **电网水平**: 湖北新能源装机 5066万kW（2025年4月底，占总装机39%），光伏4040万kW**首次超过水电**；"十五五"目标新能源8000万kW、储能1700万kW、可再生能源占比70%——高比例新能源消纳压力真实且量化。
- **AI 实践**: 组建**国网系统首个"人工智能特战队"**（电科院牵头）；"鄂营e知"是国网系统**首个**基于光明电力大模型的营销全领域AI助手（武汉/襄阳试运行后全省推广）；以光明大模型为中枢的配网工程多智能体集群（一台一策智能体、无人机工程验收智能体，近50个流程智能辅助、效率提升3倍）——电科院能源互联网中心是主责部门。
- **科研平台**: "区域新型电力系统及农村能源体系构建"**湖北省重点实验室**（研究方向含储能安全管控、分布式微电网协调运行）；武汉本地有电网环境保护国家重点实验室（中国电科院武汉分院）、特高压交流试验基地等国家级资源可借力。
- **在研项目风格**（抽样）: 电网安全风险评估及检修过渡方案智能决策、220kV开关设备停电检修应急转供（国网指南项目）——调度/检修智能决策已有积累。
- **场景资产**: "电力+气象"智慧防控系统（街道级微气象感知，武汉迎峰度夏实用化）；湖北暴雨/洪涝高发。
- **画像结论**: 三家中唯一具备"大模型应用+省重点实验室+国家级试验资源"全要素的单位，**应打"光明大模型湖北深耕+物理AI"组合拳**，不宜另起炉灶自建底座。

## 河南周口供电公司——农网大市 + 配网攻坚前线（科研弱、场景强）

- **电网水平**: 供区覆盖10县市区+4功能区（1972年成立，典型农业大市地市公司）；年度电网投资约20亿元，110kV及以上重点工程39项（含500kV周口南等14项重大工程）——处于建设攻坚期。
- **已落地亮点**: 商水县10kV线路**52秒"秒级自愈"**首次实际应用成功（复电从小时级到秒级）——配电自动化有实战基础；智能变电站二次系统配置文件管理（40分钟完成2小时工作）。
- **省级背景**: 国网河南启动**配网高质量发展三年攻坚行动**（高可靠、高承载、高韧性、高智能"四高"目标）；河南是国家能源局**分布式光伏接入承载力评估6个试点省之一**；河南技术团队牵头"千万千瓦分布式光伏承载能力安全扩容"攻关（2026年2月报道）——分布式光伏反送、变压器反向重过载、电压越限问题在河南农村极为突出；周口某县分布式光伏项目曾被国家能源局通报（备案管理问题）——痛点与合规压力双重真实。
- **农业电气化**: 河南乡村电气化工程在周口试点推广蔬菜冷冻脱水等特色用能——农业负荷场景有既往工作。
- **画像结论**: **无自有科研机构**，题目必须工程应用化、依托省电科院联合申报；"分布式光伏承载力+农网自愈+农业负荷"三张牌均有官方背书，比原清单假设的还要硬。
