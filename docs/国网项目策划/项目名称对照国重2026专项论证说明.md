# 国网辽宁电力2027年科研技术储备需求建议表 —— 项目名称对照国重2026专项论证说明

## 一、智能电网国家科技重大专项2026年度项目命名特征分析

通过对《智能电网国家科技重大专项2026年度公开项目申报指南》全文51页的系统性梳理，共提取46项指南任务，覆盖4大技术方向：

| 技术方向 | 项目数量 | 命名核心特征 |
|---------|---------|------------|
| **方向一：高比例可再生能源并网调控** | 13项 | 强调"新能源/海上风电/储能"对象 + "智能感知/主动支撑/协同运行/在线优化"技术动词 + "关键技术及装备/示范"后缀 |
| **方向二：多元用户供需互动用电与能效提升** | 11项 | 强调"配电系统/虚拟电厂/负荷管理"对象 + "数字孪生/AI大模型/韧性/互动"技术特征 + "关键技术及应用/装备"后缀 |
| **方向三：电网柔性互联与安全运行** | 10项 | 强调"柔性互联/换流阀/变压器/稳定控制"对象 + "数字孪生/协同控制/能量驱动"技术特征 + "关键技术及装备/示范"后缀 |
| **方向四：智能电网基础支撑技术** | 12项 | 强调"材料/芯片/传感器/绝缘油"基础对象 + "类脑智能/大模型/状态推演"前沿技术 + "关键技术"后缀 |

### 国重专项命名核心特征总结

1. **场景/环境定语前置**：如"高比例新能源接入下""复杂气象气候环境下""100%新能源大基地""高纬度""偏远地区"等，明确限定技术应用的独特场景
2. **核心技术对象突出**：如"构网型储能""AI大模型""数字孪生""具身智能""柔性低频组网"等，体现技术前沿性
3. **技术目标动词精准**：如"主动支撑""在线优化""协同运行""智能决策""韧性提升""辨识溯源"等，强调技术的功能性价值
4. **后缀规范统一**：
   - **重大技术装备类**："关键技术及装备"
   - **重大示范验证类**："关键技术及示范""示范工程"
   - **战略前沿技术类**："关键技术"
   - **应用推广类**："关键技术及应用"
5. **量化指标嵌入**：如"百兆瓦级""吉瓦级""100%新能源""千万千瓦级""4.5千伏/5千安级"等，体现规模与等级

## 二、五个项目名称对照优化论证

### 项目一：具身机器人方向

#### 原名称（V1）
> 面向严寒复杂环境的电力具身智能自主巡检与带电作业关键技术研究

#### 优化后名称（V2）
> **高纬度严寒环境下电力具身智能自主巡检与精细带电作业关键技术及装备**

#### 对照国重专项的命名优化依据

| 优化维度 | V1版本 | V2版本 | 对照的国重专项 |
|---------|--------|--------|--------------|
| **环境定语** | "严寒复杂环境"（较笼统） | **"高纬度严寒环境下"**（精准定位，与国重2.1"复杂气象气候环境"、2.7"复杂恶劣环境"呼应） | 方向二2.1、2.7 |
| **技术对象** | "电力具身智能" | **"电力具身智能"**（保留，与国重4.7"类脑智能"、4.8"智能运维"技术体系一致） | 方向四4.7、4.8 |
| **技术目标** | "自主巡检与带电作业" | **"自主巡检与精细带电作业"**（增加"精细"强调操作精度，与国重强调"精细/精准"一致） | 方向二2.10"精准量化" |
| **后缀** | "关键技术研究"（偏学术） | **"关键技术及装备"**（对标国重"重大技术装备类"项目命名规范） | 方向四4.7、4.8、方向二2.7 |

#### 对应国重专项论证
- **方向四4.7**：输变电设备状态感知类脑智能芯片及大模型关键技术 → 本项目"多模态融合感知+大模型语义理解"直接对应
- **方向四4.8**：面向智能运维的输变电装备状态推演技术与平台化软件 → 本项目"数字孪生训练平台+状态推演"直接对应
- **方向二2.7**：复杂恶劣环境下电网运检设备灵活可靠无线供电关键技术及应用 → 本项目"高纬度严寒环境"与"复杂恶劣环境"同属极端环境范畴，技术目标一致
- **方向二2.6**：新型配电系统数字孪生与智能运行优化关键技术及应用 → 本项目"数字孪生训练仿真平台"与该技术方向呼应
