# 第一部分：电力人工智能技术研究内容全景（回应湖北电科院）

综合国家重大专项与国网总部两级指南，2026年电力AI的研究内容可归纳为 **"1底座 + 6方向 + 1保障"** 体系：

## 1. 电力大模型底座（L0通用 → L1电力领域 → L2场景模型）

- **高质量领域数据集与思维链（CoT）数据构建**：这是两级指南的共同起点。国网总部指南005（海上风电思维链数据集）、232（调度故障处置机理知识库）、235（省地县调度可解释思维链数据集）均以此为第1条研究内容。
- **物理机理嵌入 / 机理-数据混合驱动**：纯数据驱动在电力行业不可信，指南普遍要求物理规律强约束。代表：国重3.3"新型电力系统暂态稳定科学计算大模型"（战略前沿类，轨迹生成精度与数值仿真差≤5%、速度提升100倍）、总部014"电力气象大模型物理机理嵌入"。
- **大小模型协同**：云端大模型（源模型）+ 边缘轻量化小模型自适应微调，是运检、用电安全、量测等场景的标配架构（总部084、091、212）。

## 2. 六大应用方向（按业务域）

| 方向 | 核心研究内容 | 代表指南 |
|---|---|---|
| **调度运行** | 调度故障处置大模型推理、省地县多级调度多智能体协同、运行方式智能生成、现货市场GPU加速求解、智能调控平台 | 总部232/235/044/049/067/068；国重3.3 |
| **配电网与用电** | 配电数字孪生+配电智能体（运行推演/源荷预测/故障反演/转供决策6类功能）、配网边缘智能决策、低压可靠性AI研判、配网检修生成式智能体 | 国重2.6；总部084/086/231/237 |
| **需求侧与市场** | AI大模型底座负荷管理（多模态大模型+可信智能体+边缘NPU终端）、虚拟电厂智能聚合调控（电力大模型≥700亿参数）、多智能体柔性交易、电费智能结算 | 国重2.5/2.2；总部092/099/238/102/260 |
| **设备运检** | 具身智能机器人（变配电空间智能）、输电巡检装备自主作业、装备数字孪生+智能体生成平台软件、换流阀多模态状态感知智能预警、类脑感算芯片 | 总部234/233/163/236；国重4.7/4.8 |
| **规划与防灾** | 配网规划数字孪生动态评估、跨区通道智能规划（可解释性）、大模型驱动洪涝/冰风舞灾害智能预警 | 总部231/041/125/117 |
| **企业经营管理** | 多智能体智能审计、科技项目智能审查、政策模拟、能源软科学知识库 | 总部270/271/250/245 |

## 3. 一个保障：AI安全可信

大模型多方训练数据保护（联邦/隐私增强）、智能体应用安全防护（营销2.0）、推理结果可信度评价与可解释性、电力监控系统多智能体安全认知（总部227/229/226/232-4）。

## 4. 技术趋势判断（用于交流汇报）

1. **从"模型"到"智能体"**：2026两级指南中"智能体（Agent）/多智能体"出现频次远超"神经网络"，研究范式已从训练单一模型转向"知识库+推理+工具调用+人在回路"的智能体工程。
2. **从"感知智能"到"决策智能"**：巡检图像识别类课题基本消失，新指南全部瞄准方式计算、检修计划、故障处置等**高价值决策环节**，且普遍要求思维链可解释、决策合规性校验。
3. **物理AI / 科学计算大模型**成为战略前沿：暂态轨迹生成大模型、电力气象大模型、多物理场数字孪生，是"AI for Science"在电力的落地形态。
4. **具身智能**首次成为重大专项和总部指南双热点（变配电机器人2128万为总部单项最高经费之一）。
5. **边缘智能**硬约束明确化：NPU算力≥4 TOPS、参数≤10亿、端侧推理提速3倍等量化指标开始写入考核。

# 第二部分："人工智能+"指南类项目储备体系（回应河南周口）

周口目标是**指南类项目储备建设**——即按总部指南体例（1个项目名称 + 3–5条子课题式研究内容），在同一技术领域内系统整合，形成"强行业代表性 + 全领域涵盖"的储备库。建议按 **"7大储备方向 × 每方向2–3个储备项目"** 搭建，与总部指南8大技术领域一一挂钩：

## 储备体系框架（建议共15–18项）

**方向A：电力大模型与智能体底座**（对标：数智化赋能/人工智能）
- A1 地市级电网多模态数据治理与电力大模型思维链数据集构建关键技术
- A2 大小模型协同的地市电网业务智能体构建与可信评估技术

**方向B：AI+配电网运行**（对标：配电网与用电——周口作为地市供电公司的主战场，建议投入最大权重）
- B1 配电网数字孪生体构建与智能运行推演关键技术（对标国重2.6、总部231）
- B2 面向多业务场景的配电网边缘智能决策技术（对标总部084）
- B3 基于AI的低压供电可靠性研判与治理决策技术（对标总部086）

**方向C：AI+设备运检**（对标：装备性能提升/设备数智化）
- C1 变压器等主设备数字孪生与多模态感知智能诊断（对标总部163）
- C2 配网检修计划全链条生成式智能体（对标总部237）
- C3 输配电巡检装备自主作业与具身智能（对标总部233/234）

**方向D：AI+负荷管理与需求侧互动**（对标：国重2.5，农业大市特色可做"农业负荷/农排灌"差异化）
- D1 基于大模型底座的新型负荷管理与细粒度负荷预测
- D2 分布式资源聚合与虚拟电厂多智能体协同调控（对标总部092/099/238）

**方向E：AI+防灾应急**（对标：施工防灾——周口平原农网，聚焦洪涝与冰风）
- E1 大模型驱动的变电站/配网洪涝风险智能感知与防控（对标总部125）
- E2 复合灾害下配网故障概率智能预警与应急处置（对标总部117）

**方向F：AI+营销与经营**（对标：政策与技术经济）
- F1 多模态用电安全智能检查与诊断预警（对标总部091）
- F2 电费智能结算与量费异常多智能体溯源（对标总部102）

**方向G：AI安全与支撑**（对标：数智化赋能/信息与网络安全）
- G1 电力业务大模型训练数据保护与智能体应用安全防护（对标总部227/229）

## 储备建设方法论（3步）

1. **按指南体例反向编制**：每项储备按"项目名称 + 技术领域/子领域 + 4条研究内容 + 考核指标 + 经费概算"编写，研究内容严格套用总部指南"1.xx技术研究 / 2.xx方法研究 / 3.xx装备（系统）研发 / 4.xx示范应用"的四段式。
2. **行业代表性靠"对标+差异"**：每项注明对标的国重/总部指南编号（证明是行业主流方向），再叠加周口本地场景差异化（平原农网、高比例分布式光伏、农业负荷）形成不可替代性。
3. **梯次培育**：储备项目分三档——①冲总部指南（联合省电科院/中国电科院牵头）②省公司科技项目（周口牵头）③公司级自研（练队伍、攒预实验数据），每年滚动升档。

# 第三部分：冀北智能配网中心课题纲要（8.14前 · 200–300万 · 最优先）

冀北定位是"智能配网中心"，课题应全部落在**配电网×AI**交叉带上；200–300万体量对应省公司级科技项目（总部指南单项均在600万以上，可作为技术方向背书而非直接申报对象）。以下4个课题纲要按"与两级指南对标强度 × 冀北场景独特性"排序，**建议主推课题一、课题二**：

## 课题一：基于"数字孪生+智能体"的新型配电系统运行推演与自主决策关键技术研究

**对标**: 国家重大专项2.6"新型配电系统数字孪生与智能运行优化"；总部指南231（配电网规划数字孪生，1218万）、084（配网边缘智能决策，1457万）——属两级指南双重热点。
**冀北切入点**: 冀北分布式光伏渗透率全国前列（张家口/承德可再生能源示范区），"不完备量测条件下的孪生推演"场景天然稀缺。

**研究内容**:
1. 不完备量测条件下配电系统数字孪生体构建与状态推演技术研究——多源数据融合补全、拓扑-参数自校核、毫秒级孪生体响应更新；
2. 知识嵌入与思维链推理增强的配电智能体构建技术研究——涵盖运行监测/源荷预测/安全边界感知/故障反演/转供决策等功能的智能体族；
3. 基于孪生体与智能体闭环交互的配电网自主优化决策技术研究——分布式光伏消纳、电动汽车承载力、风险防控多场景决策；
4. 配电系统数字孪生与智能决策原型系统研发及试点验证——在冀北高渗透率示范区县域电网试点。

**预期考核指标（参考国重2.6折减）**: 孪生体涵盖设备/系统/事件3大类≥10种模型；稳态推演准确度≥95%；智能体功能≥4类，闭环决策秒级；试点覆盖≥20条10kV线路，连续运行≥3个月。
**经费/工期**: 280万 / 2年。

## 课题二：配网检修与抢修计划全链条生成式智能体关键技术研究及应用

**对标**: 总部指南237"配网检修计划全链条决策的人机增强生成式智能体"（1269万）——2026总部人工智能子领域7项之一，方向确定性最高。
**冀北切入点**: 冬奥保电区域检修窗口约束严苛+冬季极寒抢修，计划编制复杂度高，人机混合增强有真实痛点。

**研究内容**:
1. 基于业务知识强化的配网检修计划编制智能体构建技术研究——检修规程/安规/典型案例知识库与检索增强生成；
2. 基于思维链推理与逻辑校验的计划可解释与合规性校验技术研究——停电影响分析、方式校核、多重约束自动核查；
3. 基于人类反馈在线趋优的检修-抢修一体化决策生成技术研究——人在回路反馈闭环、极端天气下抢修资源智能调配；
4. 生成式智能体系统研发与地市级示范应用。

**预期考核指标**: 检修计划自动生成覆盖率≥80%，合规性校验准确率≥95%，计划编制耗时下降50%以上，示范应用≥3个月。
**经费/工期**: 250万 / 2年。

## 课题三：大小模型协同的配电网边缘智能决策终端关键技术与应用

**对标**: 总部指南084（云端源模型+边缘轻量化微调）、222（配用电终端边缘智能）；国重2.5（边缘NPU终端≥4 TOPS）。
**研究内容**: 1.配网多业务云端源模型搭建与高效训练；2.边缘侧模型轻量化压缩与场景自适应微调；3.软硬协同的边缘智能终端研制（台区故障研判、可调资源就地控制）；4.云-边协同AI迭代体系与示范。
**预期考核指标**: 边缘模型参数≤10亿、推理时延≤1秒，台区故障研判准确率≥90%，示范终端≥50套。
**经费/工期**: 220万 / 2年。

## 课题四：高渗透率分布式光伏台区群多智能体协同调控关键技术研究

**对标**: 总部指南092（分布式AI低碳园区集群）、238（需求侧多智能体）；国重2.2（虚拟电厂）。
**研究内容**: 1.台区群可调资源精细化感知与聚合建模；2.基于分布式优化的台区群多智能体协同调控；3.电压越限/倒送场景下集群自治与主配协同；4.组态化AI终端与集群管控系统研发及示范。
**预期考核指标**: 聚合台区≥100个，电压合格率提升至99.9%，光伏就地消纳率提升≥5个百分点。
**经费/工期**: 200万 / 2年。

# 第五部分：基础支撑自主化关键技术指南补充分析（2026-08-13 新增）

**新增材料**: 国家能源局2026年7月29日发布《智能电网国家科技重大专项基础支撑自主化关键技术公开项目申报指南》（正文+形式审查要求+通知），这是继2026年度公开项目指南（46项）之后的**增补批次**。

## 一、指南基本盘

- **批次定位**: 聚焦"基础支撑自主化"——全部9项均为**重大技术装备类**，围绕"电网柔性互联与安全运行"（方向三，4项）和"智能电网基础支撑技术"（方向四，5项）2个方向，本质是**卡脖子组部件/材料/工业软件的国产化替代**。
- **配套比**: 3:1（低于2026年度指南装备类的5:1，门槛友好）。
- **申报窗口**: 国科管系统 **2026年8月10日8:00 — 9月13日16:00**；推荐单位（省能源主管部门/科技厅或国务院部门科技司局）9月16日16:00前确认。**窗口已开，剩约1个月。**
- **9项任务清单**:

## 三、对三家单位的影响判断

**总体判断：本批次与三家单位"电力人工智能"主线的直接交集很小**——9项中8项是材料/组部件/装备国产化（胶浸纸、橡胶、聚丙烯膜、绝缘胶、电容器、开关、套管、互感器），属电科院材料所/设备厂商的地盘，且3.4、4.4明示建议制造业企业牵头。原有策划（第一~四部分）不需要调整。

**唯一的AI相关切入点是4.5"大功率半导体器件封装多物理场耦合仿真软件"**：
- 研究内容明确要求"融合**AI代理模型、仿真智能体**技术的专用智能化高效仿真软件"，考核指标含"代理模型算法≥20种、误差≤5%、单次预测效率提升≥100倍；仿真智能体支持≥3模态输入、前后处理操作时间降低50%；GPU并行求解效率比CPU提升≥10倍"。
- 这与既有策划中"物理AI/多物理场世界模型"方向（目录中已有《V3_V4升级说明_多物理场数字孪生世界模型.md》《多物理场世界模型与四个项目适配性分析.md》积累）高度同源——**AI代理模型（surrogate model）+多物理场仿真**正是世界模型技术栈的工程化出口。
- 可行角色：网省公司/电科院不适合牵头（需EDA软件研发和器件厂验证资源，示范要求"≥5家国内厂家的二极管/晶闸管/IGBT/IGCT/SiC MOSFET研制中应用"），但可作为**参与单位**承担"AI代理模型与仿真智能体"课题，或把该任务的AI技术要素（代理模型、仿真智能体、GPU异构求解）吸收进冀北/湖北的汇报素材，作为"AI for Engineering"趋势佐证。

**对三家单位的具体动作建议**：
1. **湖北电科院**：第一部分技术全景的"物理AI/科学计算大模型"趋势条目下补充4.5作为最新证据——国家层面已把"AI代理模型+仿真智能体"写入重大专项装备类指南，物理AI从研究热点升格为国家任务。若湖北电科院有高压/材料仿真团队，4.5是少数电科院可深度参与的本批次任务。
2. **河南周口**：无直接申报机会（均为特高压/超高压组部件级任务），仅作储备体系的"行业风向"背景材料。
3. **冀北**：不受影响，课题纲要维持原方案；汇报PPT背景章节可引用本批次说明"国家在智能电网领域持续加码（2026年内已两批指南）"。
