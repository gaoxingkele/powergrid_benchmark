# Problem

## Downstream Task

day-ahead (24h) multi-region power load forecasting (short-term 1h and hierarchical Ausgrid-type settings are recorded limitations, not target tasks — see `claims.md`)

## Target-Journal Gap

The local comparator ARA collection shows that recent target-journal papers already cover many conventional baselines. This paper must therefore prove the incremental value of `CSA-LoadNet` (working name before v7: `HyG-LoadFormer`) through stronger baseline coverage, ablation isolation, significance testing, and reproducible public data.

## Datasets

- OPSD
- SimBench
- PSML
- NSRDB optional weather features
