# MA-SQLGrid Optional Figure Upgrade

This folder contains an optional visual upgrade candidate generated after the
required supplement artifact collection was assembled.

Files:

- `ma_sqlgrid_teaser_architecture_upgrade.png` - optional teaser /
  architecture upgrade candidate for the MA-SQLGrid paper.
- `ma_sqlgrid_teaser_architecture_upgrade_prompt.txt` - curated method prompt
  prepared for AutoFigure-style academic figure generation.
- `manifest.json` - provenance and visual-gate notes.

The Bianxie / AutoFigure image provider timed out twice for this paper during
TLS/API connection, so this selected candidate was generated as a deterministic
raster fallback from the same curated method story. The image was not inserted
into the original manuscript PDF. It is provided as an optional candidate for
later author review before any manuscript replacement or graphical-abstract
submission.
