# Applied Sciences framework vectors

These files are deterministic, manuscript-grounded replacements for the two
AI-generated bitmap previews. They do not contain experimental result values
and have not been inserted into either manuscript.

Run from the repository root:

```powershell
python paper_projects/applied_sciences_dual_rebuild/framework_vector_20260809/generate_vectors.py
```

Each paper directory contains an editable SVG, a vector PDF, a 450-dpi PNG for
visual inspection, caption text, the source JSON configuration, and a manifest
with SHA-256 hashes. The shared style uses live text, PDF TrueType embedding,
1.35-pt outlines, a color-blind-safe Okabe--Ito-derived palette, and redundant
hatching/line styles.
