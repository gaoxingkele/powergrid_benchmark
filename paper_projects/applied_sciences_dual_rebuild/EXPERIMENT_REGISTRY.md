# 双论文实验注册表与证据门禁

机器权威版本为 `experiment_registry.json`。注册表覆盖主实验、消融、敏感性、鲁棒性、效率、数据质量和错误分析；每项都绑定 RQ、切分协议、条件、重复、聚类单元、统计检验、目标图表、阻塞条件和主表证据等级。

## 证据等级

| 等级 | 含义 | 可否进入论文主表 |
|---|---|---|
| E0 | 只有计划，未运行 | 否 |
| E1 | smoke test，检查接口、schema 和日志 | 否 |
| E2 | 分层 pilot，完成失败率与成本审计 | 否 |
| E3 | 完整注册运行，预测与运行元数据不可变 | 仅可进入补充材料候选 |
| E4 | E3 + 独立复算 + 统计/产物审计 + 哈希 + PI 冻结 | **可以** |

主文数字只能来自 E4 canonical artifacts。E4 是证据完整度，不代表结果必须显著；阴性结果仍应如实报告并触发主张降级。

## 执行顺序

1. 先满足数据许可、冻结切分、泄漏检查和 provenance hash。
2. 运行 E1，再做约 10% 分层 E2；成本、失败率和配对完整性通过后才能正式运行。
3. 主实验先于消融/鲁棒性；阈值只在 dev 选择。
4. 形成 E3 后，由独立统计工具复算 CI、McNemar/配对检验与 Holm。
5. PI 核验全量日志、hash、笛卡尔积和 claim boundary 后晋级 E4。

## 核心阻断

- MA：D2/D3 许可或 gold 审核失败；full/compact 输入不对称；shape/gold 泄漏；sealed set 提前暴露；safe SQL 不足 100%。
- C2：底层 Wikipedia 文档跨切分；oracle label 被当成端到端协议；不同方法候选池不一致；只有最佳 seed；NERC 无真实人工审核却声明 human-gold。
- 共同：缺失逐实例结果、环境/模型/提示词/数据 hash，或人工抄录图表数值。

完整条件、指标和图表映射请直接读取 `experiment_registry.json`；它应与 `shared/stat_audit.py` 配合，用逐实例 CSV/JSONL 形成 E4 审计证据。
