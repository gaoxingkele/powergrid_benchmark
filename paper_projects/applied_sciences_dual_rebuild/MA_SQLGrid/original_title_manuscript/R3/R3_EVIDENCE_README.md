# MA-SQLGrid R3 Evidence Staging

This directory contains additive R3 material. It does not replace or modify the
frozen release-v3 files or the R2 manuscript directory.

Read evidence in this order:

1. `../../original_title_rebuild/prospective_from_freeze_offline_study_v3/SUPERSESSION_NOTICE.json`
2. `../../original_title_rebuild/prospective_from_freeze_offline_study_v3/INDEPENDENT_RELEASE_AUDIT_V3.md`
3. `evidence_tables/R3_EVIDENCE_TABLES.json`
4. `EXECUTOR_R3_TEST_REPORT.md`

Release v3 is a deterministic no-generation **descriptive** re-execution over a
historical candidate pool and previously evaluated items. Historical
`prospective`, `prespecified`, outcome-unseen, and internal `PASS 29/29` fields
are superseded. They remain in place only because frozen evidence must not be
rewritten.

The R3 executor is a new additive implementation. It is not the executor frozen
into release v3 and its new controls must not be attributed retroactively to the
80/180, 100/180, or 101/180 descriptive results.
