# Multi-state reliability protocol v3 — pre-score freeze

The frozen design contains exactly **18 total database states: 15 semantic-suite
states and 3 physical insertion-order diagnostic states**. Every archived
prediction is executed on all 18 states. The three physical permutations never
enter the semantic logical-AND operator.

Two blinded agent technical reviewers and their bound adjudication certify zero
order-sensitive items for automatic use. Therefore all 114 metadata-declared
order-sensitive questions are executed on all states but remain diagnostic
holds. The claim-promoting automatic finite-corpus estimand contains only the 66
order-insensitive questions. Exact pre-aggregation denominators are:

- 25,920 atomic rows = 2 backbones x 4 conditions x 180 questions x 18 states;
- 7,920 primary semantic rows = 2 x 4 x 66 x 15;
- 16,416 order-hold diagnostic rows = 2 x 4 x 114 x 18;
- 528 primary prediction rows before the 15-state AND and 912 held prediction rows.

Stage A remains query-blind and immutable. Stage B must verify the exact v3
freeze, the bound review-A/review-B/adjudication chain, live physical hashes of
the canonical-v2 freeze and canonical rows, all state hashes, SQLite runtime,
and both 720-key ledger contracts before executing SQL. It accepts only an
independent re-audit decision `PASS_AUTHORIZE_FORMAL_SCORE` with every required
gate `PASS`. Because that audit is necessarily created after this freeze, a
separate launch-approval companion must bind the exact freeze SHA and the audit
file's path, SHA-256, and bytes. The companion schema/policy is frozen here.

The primary suite is logical AND over exactly the 15 semantic states. Every
error remains in its declared denominator. T0 outcomes must reproduce all 1,440
canonical-v2 snapshot execution labels before atomic output is committed.

The frozen analysis uses a 70-cluster normalized-SQL map, seed 20260805,
100,000 cluster sign-flip draws, 20,000 cluster bootstrap draws, nine fixed
tests (scope, hint, interaction for Qwen and Granite plus three Granite-minus-
Qwen modifiers), and one nine-test Holm family. Intervals are labelled
composition-sensitivity intervals; the estimand is the finite 66-question
subset, not a population.

Atomic rows trace to suite JSONL/CSV, the nine-test CSV, TeX table and SVG via
SHA-256 lineage. The release builder hashes every artifact; the independent
release verifier enforces denominators, family size, artifact identity and
CSV-to-TeX/SVG source hashes.

This remains a retrospective automated gold-SQL agreement stress test. It is
not a preregistration, a human semantic audit, or operator-certified grid data.
