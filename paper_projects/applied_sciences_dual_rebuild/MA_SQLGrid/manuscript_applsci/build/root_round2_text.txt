                                       frozen 700-call component study then isolated presented value evidence (E1) and reference-       19

                                     2. Related Work                                                                                    101


                                     2.1. Text-to-SQL and Cross-Database Evaluation                                                     102


                                           Text-to-SQL research has progressed from template and grammar systems to neu-                103

                                     ral parsers and instruction-tuned language models. Spider established a cross-domain,              104

                                     cross-database setting in which train and test databases differ, forcing models to interpret       105

                                     unfamiliar schemas rather than memorize query templates [1]. Its difficulty also highlighted       106

                                     the need to evaluate structural decisions such as joins, nesting, aggregation, grouping, and       107

                                     ordering. Later benchmarks and surveys catalogued continuing challenges in schema                  108

                                     linking, compositional generalization, ambiguous questions, and realistic database content         109

                                     [3,6,7].                                                                                           110

                                           Execution-based evaluation answers a question that string match cannot: whether              111

                                     the predicted query produces the intended result on a particular database state. Exact             112

                                     SQL match can penalize semantically equivalent queries, whereas execution equality can             113

                                     fail to distinguish nonequivalent queries on an insufficiently discriminating database.            114

                                     Applied work should therefore freeze the execution contract, retain the predicted SQL,             115

                                     and state the database boundary. In this study, strict result equality is primary; projected-      116

                                     column conformity and error categories are separate diagnostics. We do not claim semantic          117

                                     equivalence beyond the frozen database instances.                                                  118

                                           Constrained decoding and execution guidance reduce invalid outputs. PICARD incre-            119

                                     mentally rejects tokens that cannot form admissible SQL [2]. Execution-guided approaches           120

                                     test candidate queries against a database and use failures or results during selection. MA-        121

                                     SQLGrid uses a lighter boundary: the generator is prompted once under a frozen condition,          122

                                     then a deterministic parser and read-only validator classify and execute the output. No            123

                                     gold SQL or gold result is available during generation or candidate selection.                     124

                                           Large language models make prompt context a central design variable. Schema seri-            125

                                     alization, examples, column descriptions, value samples, and explicit output instructions          126

                                     compete for a finite context budget. Empirical studies show that model performance                 127

                                     can depend strongly on representation and demonstration choices [4,5,8]. Yet combined              128

                                     prompt revisions do not reveal causal contribution. Our factorial design estimates two             129

                                     interventions separately and shows that a prompt feature can improve response conformity           130

                                     more reliably than semantic execution.                                                             131

                                     2.2. Schema Linking, Context Selection, and Response Contracts                                         132


                                           Schema linking connects question spans to tables, columns, values, and relationships             133

                                     [9–11]. A full schema preserves all available elements but may introduce distractors, long-            134

                                     range dependencies, and token cost. Compact context aims to retain question-relevant                   135

                                     elements while removing low-relevance structure. This creates a recall–precision trade-off:            136

                                     excluding a needed join key is catastrophic, while retaining unrelated tables may confuse a            137

                                     generator. Deterministic introspection and selection make this trade-off auditable.                    138

                                           Output contracts describe what a response should contain. In text-to-SQL, such                   139

                                     guidance can specify projected fields, row granularity, ordering, aggregation, group-                  140

                                     ing/HAVING, or LIMIT behavior. The intervention tested here is consequently broader                    141

                                     than an answer-format hint and is explicitly corpus-tailored. We record only a common-                 142

                                     target projected-column indicator independently of execution equality. The two endpoints               143

                                     must not be merged: high column-count conformity shows reception of one structural                     144

                                     instruction, not correctness of the returned database content.                                         145

                                           Recent domain-oriented systems combine schema retrieval, value grounding, decom-                 146

                                     position, and repair, including CHESS and the Applied Sciences DKA-SQL study [12,13].                  147

                                     DKA-SQL is a direct power-grid text-to-SQL precedent, so our novelty is not being the                  148

                                     first grid text-to-SQL framework. Its published evidence, workflow, models, and corpora                149

                                     differ materially from ours, and no official implementation or immutable prompt/code                   150

                                     release was located in the Round-1 audit; we therefore make no numerical superiority or                151

                                     reproduction claim. A 2 × 2 design estimates the bundled context-package effect, composite-            152

                                     hint effect, and difference-in-differences interaction. Repeating the same design for two              153

                                     backbones is a sensitivity analysis, not a general model-family study.                                 154



                                     2.3. Power-Grid Databases and AI-Assisted Access                                                       155


                                           Power-system datasets mix network topology, asset attributes, time series, costs, con-           156

                                     straints, maintenance records, and event narratives. RTS-GMLC provides a reproducible                  157

                                     test-system resource with buses, branches, generators, loads, renewable profiles, reserves,            158

                                     and dispatch-related data [14]. SimBench supplies benchmark networks for multiple volt-                159

                                     age levels and scenarios [15]. Both resources can be transformed into relational databases             160

                                     that exercise selections, joins, aggregation, ranking, and topology-oriented questions.                161

                                           These public engineering resources are attractive for external validation, but database          162

                                     availability does not create a text-to-SQL benchmark automatically. Natural-language                   163

                                     questions and reference SQL must be semantically reviewed, units and tie handling must                 164

                                     be specified, and ambiguous projections must be resolved. Automatically generated pairs                165

                                     are useful for building and testing the pipeline, yet their agreement with a model output is           166

                                     not human-gold accuracy. The present paper treats the external resources accordingly.                  167

                                           Recent work applies language models to grid-domain information extraction, includ-               168

                                     ing a semantic-dependency and lexical-embedding RoBERTa design in this journal [16].                   169

                                     Relational-provenance research in the same venue further motivates preserving query and                170

                                     source lineage [17]. The central risk is that fluent output can be mistaken for validated              171

                                     engineering reasoning. Text-to-SQL offers a comparatively inspectable interface because                172

                                     the generated query and returned rows can be reviewed. That advantage depends on a                     173

                                     read-only execution policy, stable database provenance, and conservative claims about                  174

                                     what the execution demonstrates.                                                                       175

                                     schema, and yi⋆ a reference query used only by the offline evaluator. For context-package                          179

                                     condition c ∈ {0, 1} and composite-hint condition h ∈ {0, 1}, the model produces                                   180

                                     template. The two executed packages are                                                                            183



                                                 Ci,0,h = Pfull (Si , V ) ⊕ hH ( xi ),       Ci,1,h = Pcompact ( xi , Si , V ) ⊕ hH ( xi ),      (2)    184

                                     checks a single SELECT or WITH form, and executes admissible SQL against a database                                193

                                     opened read-only. It never sees yi⋆ or its result while selecting a candidate.                                     194

                                          The experiment estimates prompt intervention effects, not a sealed generalization score.                      195

                                     3.3. Prompt Packages and Factor Audit                                                               210


                                            The full package is constant across questions apart from the question text: all eight-       211

                                     table DDL and a sorted global dictionary drawn from permitted non-ID categorical, date,             212

                                     and text columns. The compact package first matches permitted values, applies frozen                213

                                     corpus-tailored phrase and normalization rules, selects seed tables/columns, expands                214

                                     foreign-key connections to at most six tables, and serializes joins, matched values, and            215

                                     predicate hints. If selection omits a needed element, the model cannot recover it from gold         216

                                     metadata.                                                                                           217

                                            The composite hint can specify the expected projected-column count, row granularity,         218

                                     ordering need, COUNT/AVG/SUM/MIN/MAX, GROUP BY/HAVING, exact projection fields, de-                 219

                                     scending order, or LIMIT. Its serialization also differs between full and compact packages.         220

                                     The estimand is therefore the effect of this frozen composite package as actually delivered;        221

                                     it is not the effect of a generic answer-format sentence.                                           222

                                            For the representative question “How many alarmed readings does each asset                   223

                                     have?”, F00 contains complete DDL and the global dictionary; F01 adds a two-column,                 224

                                     multi-row, ordered COUNT(*) hint. F10 contains six graph-expanded tables, the                       225

                                     sensor_readings.asset_id = assets.asset_id join and the normalization alarm_flag                    226

                                     = 1; F11 adds the corresponding two-column, multi-row, ordering and count instructions.             227

                                     Across all 180 questions, question ID, database, common safety instruction, model settings,         228

                                     one-call policy, parser, validator, and offline evaluator are invariant. Prompt-field auditing      229

                                     confirms that F00/F01 always contain full DDL and the global dictionary, F10/F11 always             230

                                     5. Discussion                                                                                                                                                  512


                                     5.1. What the Evidence Supports                                                                                                                                513


                                          The clearest factorial result is the composite hint on the common-target projected-                                                                       514

                                     column manipulation check. Both backbones show increases larger than 0.35 and survive                                                                          515

                                     the separate secondary family. Explicit structural and SQL-operation instructions therefore                                                                    516

                                     change projected-column adherence in this bounded experiment. Because the hint also                                                                            517

                                     contains aggregation, grouping, projection, ordering, and limit rules, this result cannot be                                                                   518

                                     reduced to generic formatting advice or promoted as independent semantic validation.                                                                           519

                                          Factorial execution is more conditional. All nine primary tests fail Holm correction,                                                                     520

                                     even where composition-sensitivity intervals exclude zero. This divergence is not contradic-                                                                   521

                                     tory: randomization tests implement the predeclared finite-set promotion rule, whereas the                                                                     522

                                     intervals show how estimates change when the empirical group composition is reweighted.                                                                        523

                                     Neither is evidence from a random sample of databases or questions.                                                                                            524

                                          The compact/domain-grounded package does not show a uniformly positive indepen-                                                                           525

                                     dent effect. For Qwen its execution main effect is negative with an upper interval endpoint                                                                    526

                                     at zero; for Granite it is small and uncertain. The package is substantially shorter, but                                                                      527




                                                                                                                                                https://doi.org/10.3390/app1010000
Version August 5, 2026 submitted to Appl. Sci.                                                                                18 of 22




                                     it simultaneously changes schema coverage, value presentation, join serialization, and              528

                                     normalization. It is therefore neither a pure schema-selection ablation nor evidence that           529

                                     shorter prompts improve accuracy.                                                                   530

                                           The prospective component results sharpen but do not universalize the architecture.           531

                                     Presented value evidence passes the efficacy rule for Qwen only; its zero Granite estimate          532

                                     and non-promoted modifier preclude a replicated or universal value-grounding claim. The             533

                                     deterministic selector yields rescues for both backbones but does not pass either adjusted          534

                                     test. Deployment teams should therefore validate the complete model–prompt–database                 535

                                     combination under execution rather than assume that a stage label guarantees benefit.               536



                                     5.2. Projected Columns versus Semantic Correctness                                                  537


                                           The gap between the common-target diagnostic and execution equality is a warning              538

                                     against surface-only evaluation. In Qwen F01, projected-column conformity is 0.9667 while           539

                                     execution equality is 0.7167. In Granite F01 the corresponding values are 0.8778 and 0.5556.        540

                                     A model can return the requested number of columns yet select the wrong table, field, filter,       541

                                     join, or aggregation.                                                                               542

                                           The projected-column diagnostic remains useful because it localizes one interface             543

                                     failure and shows that an intervention is received. It should be reported next to, not              544

                                     substituted for, execution. Row granularity and ordering were present in prompts but are            545

                                     not validated by this endpoint. Where a database state is insufficiently discriminating,            546

                                     manual semantic review or test-database augmentation is also needed.                                547



                                     5.3. Implications for Power-Grid Data Access                                                        548


                                          An operational interface should expose the generated SQL, database snapshot, schema            549

                                     context, and execution status. Read-only enforcement prevents accidental mutation but               550

                                     does not prevent a semantically wrong query from returning plausible rows. High-                    551

                                     consequence decisions therefore require review of both the SQL and the source data.                 552

                                          The external diagnostic is useful precisely because it fails visibly. Missing-column           553

                                     errors indicate that the model inferred familiar field names rather than grounding to the           554

                                     actual schema. Prompt repair should target these mismatches, then be evaluated on new or            555

                                     sealed items rather than repeatedly optimizing against the same 91 visible candidates.              556

                                          RTS-GMLC and SimBench broaden the engineering structures represented in the                    557

                                     project: topology, generation, constraints, time series, and network elements. Their inclu-         558

                                     sion does not by itself validate maintenance-database generalization. A credible external           559

                                     benchmark needs domain experts to verify terminology, units, expected projections, accept-          560

                                     able equivalences, and tie rules.                                                                   561



                                     5.4. Reproducibility and Negative Results                                                           562


                                           The quarantined Qwen incident demonstrates why result directories need immutable              563

                                     identity and process accounting. A directory containing more generations than the regis-            564

                                     tered Cartesian design is not repaired by truncating it. The clean rerun provides a separate        565

                                     evidence chain, and the audit confirms that the contaminated output contributed no canon-           566

                                     ical row.                                                                                           567

                                           Hash-bound artifacts reduce transcription and provenance errors. They do not make             568

                                     an exposed test partition sealed, resolve a missing data license, or turn automatic candidates      569

                                     into human labels. Reproducibility and evidential validity are related but distinct.                570

                                           The compact/domain-grounded package NO–GO is a useful result. The stage remains               571

                                     available for future selectors, but the paper does not assign it an independent benefit that        572

                                     the current data do not support. The prospective E2 selector also remains a NO–GO for               573

                                     promoted efficacy despite descriptive rescues. E1 supports presented value evidence for             574




                                                                                                   https://doi.org/10.3390/app1010000
Version August 5, 2026 submitted to Appl. Sci.                                                                                19 of 22




                                     one snapshot only. BIRD model baselines remain unexecuted, and the E4 latency records               575

                                     remain diagnostic rather than comparative-efficiency evidence.                                      576



                                     5.5. Limitations                                                                                    577


                                           The primary corpus is one synthetic 8-table, 98-row maintenance-oriented database             578

                                     and only 180 evaluation questions. Questions map to 70 normalized-SQL dependence-                   579

                                     proxy groups, 58 of them singletons; grouped procedures respect this mapping, but it                580

                                     is not an authoring-template identifier and the corpus cannot represent the diversity of            581

                                     production schemas, permissions, missing values, units, or data quality.                            582

                                           The evaluation partition was visible in earlier development. Gold fields are excluded         583

                                     from prompts and the formal runs are frozen, but prior analyst exposure prevents a sealed-          584

                                     test claim. The two model snapshots use Q4_K_M quantization and one llama.cpp revision.             585

                                     Results may differ for full-precision weights, alternative quantization, other runtimes,            586

                                     stochastic decoding, or hosted models.                                                              587

                                           Only one generation is made per factorial prompt and one formal response per com-             588

                                     ponent condition. Temperature zero and fixed runtime settings improve repeatability, but            589

                                     they do not quantify decoding variance or server nondeterminism. The second backbone                590

                                     is sensitivity analysis, not replication, and no cross-backbone component effect satisfies          591

                                     a replication rule. Multi-run inference would require a prospectively frozen hierarchical           592

                                     analysis and materially greater compute.                                                            593

                                           Execution equality is database-state dependent. Different SQL statements may agree            594

                                     accidentally on the current data, and minor projection differences may be judged wrong              595

                                     under the strict contract. The contract is intentionally fixed, yet no single automatic metric      596

                                     captures every notion of semantic equivalence.                                                      597

                                           E4 records paired telemetry under a frozen order, but the required efficiency attestation     598

                                     is missing. Token deltas remain valid descriptive outputs; latency and throughput are               599

                                     diagnostic, and no energy or memory measurement supports deployment-efficiency claims.              600

                                     A confirmatory efficiency study requires independently verified process isolation, thermal          601

                                     state, common hardware, and separate generation/database timing.                                    602

                                           External candidates have not completed human review. Their automatic references               603

                                     and the Qwen diagnostic are development evidence only. No claim of RTS-GMLC or                      604

                                     SimBench accuracy, cross-database generalization, or operational readiness follows from             605

                                     them.                                                                                               606

                                           GridDB redistribution permission is unresolved, and derived RTS-GMLC and Sim-                 607

                                     Bench artifacts have source-specific notice and database-license obligations. A public              608

                                     artifact release must undergo human license review and receive a permanent repository               609

                                     DOI. Author identities, contributions, funding, conflicts, acknowledgments, and AI-use              610

                                     disclosure also require author confirmation.                                                        611



                                     5.6. Future Work                                                                                    612


                                           The immediate external study should complete two independent expert reviews of                613

                                     all candidates, retain disagreements, and adjudicate them under the frozen manual. A                614

                                     subsequent confirmatory set should be newly authored or deeply rewritten after the prompt           615

                                     and schema-repair work is frozen. This preserves a genuinely unexposed test.                        616

                                           The compact/domain-grounded builder should be redesigned around reference-free                617

                                     coverage safeguards. Candidate columns and relationships could be accompanied by                    618

                                     explicit connectivity checks and a fallback to the full package when join paths appear              619

                                     incomplete. The observed offline table/column recall cannot be used online because it               620

                                     depends on gold-required fields. Any replacement safeguard constitutes a new intervention           621

                                     and must be evaluated prospectively.                                                                622




                                                                                                   https://doi.org/10.3390/app1010000
Version August 5, 2026 submitted to Appl. Sci.                                                                                    20 of 22




                                          The completed E2 replay should be followed only by a newly frozen selector revision;               623

                                     tuning against its visible rescues would make the present set development data. Efficiency              624

                                     confirmation requires controlled warm and cold runs, common hardware, token accounting,                 625

                                     resident and accelerator memory, energy where possible, and separate model-generation                   626

                                     and SQL-execution latency.                                                                              627

                                          After the remaining freeze gates and independent sign-off, the BIRD Mini-Dev draft                 628

                                     can add transparent direct, decomposition, schema-selection, and bounded execution-                     629

                                     feedback baselines on the same two snapshots. Its 500/500 SQLite 3.40.1 gold-query                      630

                                     preflight is a mechanical gate, not model evidence. It must not be described as DKASQL                  631

                                     reproduction, because no official implementation was found. Additional backbones, sizes,                632

                                     quantizations, decoding settings, and repeated runs would test whether the finite-set                   633

                                     execution contrasts persist.                                                                            634



                                     6. Conclusions                                                                                          635


                                          MA-SQLGrid provides an auditable case study of context grounding for power-grid                    636

                                     text-to-SQL. Across two independently audited local backbones, a GridDB-tailored com-                   637

                                     posite structural/SQL-operation hint improves a common-target projected-column ma-                      638

                                     nipulation check, but none of nine primary factorial execution tests survives family-wise               639

                                     correction. The compact/domain-grounded package does not show an independent posi-                      640

                                     tive execution effect. In the separate 700-call component study, presented value evidence               641

                                     improves Qwen execution under the frozen rule but not Granite execution; deterministic                  642

                                     candidate selection is not promoted for either snapshot.                                                643

                                          The practical conclusion is not that one prompt recipe or component universally                    644

                                     wins. Model, schema/value context, handcrafted normalization, operation guidance, and                   645

                                     candidate selection form a coupled system that must be evaluated with database execution.               646

                                     Hash-bound ledgers, explicit finite-set families, composition sensitivity, sealed candidate             647

                                     selection, and negative results make this bounded conclusion reproducible. External RTS-                648

                                     GMLC and SimBench work remains a mechanically validated pilot until independent                         649

                                     experts certify the question–SQL pairs and a sealed follow-up set is executed; BIRD remains             650

                                     an unexecuted model protocol despite its completed gold-query preflight.                                651
