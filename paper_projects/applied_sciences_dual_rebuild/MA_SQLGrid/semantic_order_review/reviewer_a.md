## Scope and independence

This is an **agent technical review**, not a human domain annotation. I reviewed only natural-language text, gold SQL, `order_sensitive` metadata, and schema constraints. I did **not** read model predictions, model outputs, semantic-diagnostic outcomes, or result tables.

## Decision rule

- `TOTAL_ORDER_VALID`: order is linguistically material and gold supplies a semantically declared total order without unresolved cutoff ties.
- `TIE_AMBIGUOUS_HOLD`: rank/time selection is material, but ties can change order/cutoff or SQL uses an undeclared tie policy.
- `ORDER_METADATA_INCONSISTENT`: the question does not request order, while order-sensitive grading rejects equivalent permutations.

Technical total ordering is separate: a primary/group key may make SQL deterministic without making row order semantic.
