## Closure rules

- “Addressed” requires an artifact path, immutable hash, and an executable or human-verifiable acceptance check.
- A clean rerun cannot retroactively validate R1; v0.1/v0.2 remain incident/corrective-history artifacts.
- If the complete-PDF builder cannot unambiguously identify a reference boundary, the report is excluded with a reason rather than manually repaired after seeing outcomes.
- If the development-only CF gate does not show a non-degenerate, non-identical signal, v0.3 does not run the test set under a counterfactual-effectiveness claim.
- The v0.3 evaluation on the already viewed 16-report set is post-audit corrective and exploratory regardless of preregistration or multiplicity correction; only a new sealed holdout could support confirmatory language.
- LLM assistance may produce machine-silver exploratory labels only; it is never described as qualified expert adjudication.
- Until the exact v0.3 GitHub release/tag is synchronized and verified from a fresh clone, no manuscript sentence may state that the public repository reproduces R2.
