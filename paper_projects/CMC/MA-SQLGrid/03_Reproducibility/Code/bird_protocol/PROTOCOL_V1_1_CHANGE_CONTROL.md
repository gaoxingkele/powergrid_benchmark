# MA-PUBLIC-BIRD-MINIDEV-v1.1 change control

Status: **FROZEN_NOT_RUN after manifest construction and audit**.

## Authorized change

Protocol v1.1 is an additive correction over immutable v1.0.  The sole
behavioral change is that `freeze_public_baseline_v1_1.safe_execute` catches
`sqlite3.Warning` in addition to `sqlite3.Error` and routes both through the
existing frozen `classify_sqlite_error` function.  Under the pinned Python
3.10.11 / SQLite 3.40.1 runtime, a multi-statement prediction is therefore
recorded as `OTHER_EXECUTION_ERROR` instead of terminating the process.

The live shared-workspace v1.0 module and test file were concurrently edited
after the first v1.1 freeze construction.  They are not dependencies of v1.1.
Instead, `freeze_public_baseline_v1_0_snapshot.py` and
`test_public_baseline_freeze_v1_0_snapshot.py` mechanically recover the exact
historical bytes declared by the v1.0 freeze (SHA-256 `d715...89d23` and
`ffc0...91a01`).  The live drifted files are preserved, not overwritten.
The live `BASELINE_PROTOCOL_FREEZE.json` was subsequently regenerated by the
same concurrent workflow and is also excluded.  v1.1 records its observed hash
for provenance while binding the historical v1.0 identity
`29c780...b42af5` as a constant; all executable dependencies are independently
hash-bound in the v1.1 manifest.

because rebuilding them under a different protocol string would change call
order and hashes.  The v1.1 freeze explicitly records this inheritance.

`BASELINE_PROTOCOL_FREEZE_v1_1.json` and acknowledging the 7,476-call maximum.
