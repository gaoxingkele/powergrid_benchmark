## 1. 目标、约束与完成定义

目标是在不改变既有结果含义、不制造新证据的前提下，先修复发布一致性，再建立公平比较、组件因果诊断、系列级统计和人工结构评价的证据链。

硬约束：

- 不把 strict variant 的最高观测结果弱化或隐藏。
- 不把 equal-unit 结果写成 length-controlled superiority。
- 不把自动 lexical role、typed edge 或 path 当作专家验证的工程因果关系。
- 不把 NERC 技术报告直接等同于真实维护工单。
- 新引用、外部数据、专家身份、作者邮箱、仓库 release 和数值结果均须有可核验证据；否则标为“待核实”。

完成定义：全部 P0 关闭；根据最终主张强度完成必要 P1；正文、补充材料、代码、数据、哈希、manifest、PDF 与 QA 来自同一次冻结；编译和干净环境验收通过。

## 4. P1：决定核心科学主张能否保留

### C-P1-01 布局感知 extraction-unit 重建

设计：区分正文句、标题、列表项、表格行、页眉页脚和脚注；修复跨行/跨页融合。旧版与新版都报告单元数、词数/字符/WordPiece 分布、表格污染率、超过编码上限比例和抽样人工有效率。

依赖：在匹配预算和嵌入敏感性实验之前完成。  
验收：主实验不再由 100--270 词的融合块驱动；抽样规则、标注记录和排除数可复核。

### C-P1-02 匹配词数或 Token 预算主比较

设计：预先冻结至少短、中两个预算；所有方法在选择时受同一预算约束，不能先选长单元再事后截断。比较当前 Full、推荐最终版本、normalized no-path、Semantic-MMR、TextRank、Role、Lead 和经核验的强基线。

报告：ROUGE-1/2/L、实际长度、冗余、覆盖、来源忠实度；若加入语义指标，先说明其适用边界。  
验收：各方法平均实际长度落在预定义容差内；主结论来自匹配预算表，equal-unit 降为补充分析。

### C-P1-03 嵌入截断审计

设计：记录模型 revision、tokenizer、最大长度、padding/truncation；统计所有候选的 token 长度和被截断比例；比较默认截断、布局短单元、分块池化和可行的长上下文编码。

验收：正文和复现配置均能定位模型身份；若编码方式改变排序，结果和讨论必须显式报告。

### C-P1-04 平衡调参与强基线

设计：所有可调系统使用同一开发系列和相同预定搜索预算；公开参数空间、配置数、选模目标和 tie rule。新基线的论文与实现身份须逐条核实后再加入。

验收：主要比较不再出现“C2GES 搜索 144 配置、其他系统默认参数”的不对称。

### C-P1-05 干净组件消融

最少条件：relevance only；+ role score；+ role-group reservation；+ untyped graph salience；+ typed edges；+ normalized path-deletion；加入/移除 redundancy；当前 Full；当前 unrenormalized strict 历史对照。

原则：一次只改变一个机制；移除正向项时保持正向总尺度及冗余惩罚相对尺度可比。  
报告：匹配预算性能、结构人工精度、选择 Jaccard、路径覆盖、冗余和跨系列稳定性。  
验收：每个核心模块都有直接判断；无收益模块从默认系统或核心贡献中降级。

### C-P1-06 人工结构有效性

设计：按报告系列、布局和自动置信度分层抽样；至少两名具备相关技术文档经验的独立标注者判断单元有效性、角色/abstain、边证据与方向、路径可解释性、来源忠实度和关键遗漏。

报告：标注指南、盲化方式、一致率、仲裁前分歧、仲裁结果、precision/recall/F1 及分类型错误。  
验收：阈值在看结果前定义；低于阈值的角色或边被重设计或降级为 heuristic textual proxy。

### C-P1-07 系列级统计

设计：以 `report_series_id` 为 cluster，执行 cluster bootstrap、系列块 sign-flip/置换和 leave-one-series-out；预先决定报告等权或系列等权 estimand，另一种作为敏感性分析。

验收：主表报告每个系列的报告数、配对效应、区间和 Holm 结果；系列级不支持时使用“不确定”，不得继续写“显著优于”。

### C-P1-08 新的未见系列

在 C-P0-01 冻结后才打开完整未见报告系列；整套系列不得进入开发。现有 test 保留为 `retained descriptive test set`，新外部结果单列，不与旧 test 混合。

验收：可证明测试哈希在冻结前存在，但模型、阈值和误差分析未接触其标签。

## 7. 结果驱动的决策规则

- normalized path-deletion 在匹配预算和新留出集仍无收益：默认方法采用稳定的无路径版本，路径项改为实验模块/负向结果。
- 自动角色或边精度不足：重设计规则，或统一称为 heuristic textual proxy。
- 匹配预算后不优于基线：删除系统优越性叙述，突出确定性、来源链接和透明负向诊断。
- 专家任务无效：删除 reading-aid 效果措辞，只保留可导航这一系统属性。
- 系列级区间跨零或校正后不支持：主结论写为不确定，逐报告结果不得覆盖系列级解释。
- 干净环境不能重建：不得把 `reproducible` 作为无条件核心卖点。
