# Exploratory external series v0

This corpus is deliberately classified as **exploratory**, not prospective-confirmatory. Source metadata or search snippets were exposed before the formal E1 protocol could be frozen. The reports are useful for testing cross-organization behavior and for discovering implementation failures, but they cannot satisfy the manuscript's strict prospective E1 claim.

Source PDFs are private local inputs. Only hashes, non-verbatim audits, derived metrics, and selected unit identifiers may be released pending rights review.
