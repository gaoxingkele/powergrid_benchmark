Purpose:
- Implement the complete AB-0--AB-6 chain.

Run 1 is the first development-only implementation pilot. Run 2 supersedes it
for implementation diagnostics because G-U was changed to use the same lexical
overlap function as G-T; this removes a tokenization confound. Neither run is E1
or confirmatory E3. Neither accesses an external test set, and neither may be
cited as evidence of generalization or manuscript superiority.
