# C²GES 下一步实验增补计划（2026-09-26）

依据：`C2GES_DATASET_QUALITY_AND_STATISTICS_20260926.md`（含功效天花板与数据资产盘点）。
原则：**先定判据与规模，再取数；先冻结，再跑分；只报该层能支撑的主张。**

---

## 0. 一句话计划

把现有"6 份电网事故 + 7 份市场耦合 + 6 份 NERC 增量"的 19 文档外部语料，**扩到"电网事故族 ≥12、市场耦合族 ≥12"（合计 ≥24）**，用**单一定义的参考摘要 + 一致词预算（110/260 词）**重跑，并按预先声明的判据判定"角色层是否可复现出增益、路径层是否复现为零/负"。同时把**功效上限写进结果**，让"不显著"不被误读为"无效应"。

---

## 1. 为什么是这个规模（功效算术）

### 1.1 可显著下限（决定"能不能过线"）

精确符号翻转 + Holm（家族 k 个对比）下的**最小可能** adjusted p = k × 2/2ⁿ：

| n | k=4 | k=6 | 结论 |
|---:|---:|---:|---|
| 7 | 0.0625 | 0.0938 | **永远过不了 0.05**（现有试点的处境） |
| 8 | 0.0313 | 0.0469 | 勉强可过，但要求 8/8 同号 |
| 10 | 0.0078 | 0.0117 | 可用 |
| **12** | **0.0020** | **0.0029** | **推荐下限** |
| 15 | 0.00024 | 0.00037 | 宽裕 |

### 1.2 需要多少样本才有"实际功效"

| 目标 | 方法 | 80% 功效所需 n |
|---|---|---:|
| 正号比例 70% | 精确符号检验（α=0.05 双侧） | ~49 |
| 正号比例 75% | 同上 | ~30 |
| 正号比例 80% | 同上 | ~20 |
| 效应 0.5 sd | 配对 t 检验（近似） | ~32 |
| 效应 0.8 sd | 同上 | ~13 |

**实测效应量级**：外部语料 TextRank−no-path ≈ +0.023，sd 0.034–0.067（≈0.3–0.7 sd）；Full−no-path ≈ −0.0029，sd 0.0056（≈0.4 sd）。按此，**n=12 只够"能不能过线"，要"稳"需要 20–30**。

**结论**：目标设为 **每族 ≥12（硬下限）→ 15（争取）→ 合计 24–30**；若某族确实只能凑到 8–10，就在报告里显式写出该族的功效上限。

## 2. 取数计划（按优先级）

### 2.1 已证明可用的通道（复用手法）

| 通道 | 手法 | 适用 |
|---|---|---|
| Wayback CDX 枚举 + 原站直连 | `web.archive.org/cdx/search/cdx?url=<host>/<path>&matchType=prefix&filter=original:.*\.pdf&fl=original,timestamp&collapse=urlkey&limit=N&output=json`，再用 aria2c 直连原站；403 时改 `web.archive.org/web/<ts>id_/<url>` | 任何机构站 |
| ENTSO-E 对象存储 | 枚举后从 `eepublicdownloads.blob.core.windows.net` **直连**（本环境无 403） | ENTSO-E 全部 PDF |
| NERC | CDX 枚举 → Wayback `id_` 副本（直连 403） | NERC 事件报告 |

### 2.2 目标清单

| 优先 | 目标语料 | 预期可获 | 备注 |
|---|---|---|---|
| 高 | **ENTSO-E 电网事故族**（现 6 → 目标 12+） | 2006 UCTE 分裂、历年 System Defence/Incident 报告、各 TSO 的 factual report | 唯一同时具备"真实 + 超长 + 官方摘要"的语料；稀有，需把"事故类 factual/incident/final report"定义写清 |
| 高 | **ENTSO-E 市场耦合族**（现 7 → 目标 12+） | SDAC/SIDC 历次 partial decoupling 报告（2019–2025） | 格式统一、易累积；**必须单独成族，不与电网事故混池** |
| 中 | **NERC 新事件报告**（现 6） | CDX 再枚举 2003–2020 老报告 | 多为短 incident review；只有含摘要章节者入选 |
| 中 | 其他机构站点（需先探可达性） | Transpower NZ、Svenska kraftnät/Fingrid/Statnett 扰动统计、ERCOT/CAISO 报告、India CEA、EU ACER | 逐站探测；DOE OE-417 / AEMO / NESO / GAO 在本环境已确认为 403/404 |
| 低 | 合成压力集扩版 | — | 只能验软件，不进外部效度主张 |

### 2.3 入选门禁（取数即筛）

1. 有**完整文本层**（非扫描件，可用 PyMuPDF 抽字验证）；
2. 前 25 页内存在**可识别的官方摘要章节**（Executive / Management / Summary 任一），且该节 **≥100 词**；
3. 摘要之后的候选区 **≥20 个单元**；
4. 同族内**去重**（同事件的多版本保留最终版：final > interim > note）；
5. 记录**许可与再分发状态**（正文与逐字文本一律不随包分发）。

## 3. 协议 v2 设计（跑分前冻结）

| 项 | 规则 | 与 v1 的差异 |
|---|---|---|
| 参考定义 | **每族一个定义**：整篇第一个 summary 章节（含其子节），到同级或更高级标题为止 | v1 允许 Executive/Management/Summary 混用；v2 要求族内一致 |
| 抽取 | PDF → Markdown（`pymupdf4llm`）→ 段落单元 | 同 v1.4，但记录每篇的转换哈希 |
| 预算 | 110 / 260 词；**另加"等句数 K=5/10"作对照**，用于显式量化"等单元 vs 等词"的预算效应 | **新增**：把历史层与外部层放在同一坐标下比较 |
| 比较 | no-path C²GES、Full C²GES(0.10)、TextRank、（可选）Semantic-MMR、Lead | 新增 Lead（内部等词预算下最强） |
| 端点 | ROUGE-L F1 主；ROUGE-1/2 与冗余率描述性 | 同 |
| 分析单元 | 文档；族内配对；**不跨族合并** | 同 |
| 统计 | 族内配对符号翻转（n≤20 精确枚举，n>20 用 10⁵ 次随机符号翻转）＋族内 Holm；报告**功效上限**与**零质量** | **新增**：功效上限与零质量必须报 |
| 判据 | **H1**：角色层（role evidence / reservation）相对 no-path 的符号一致率 ≥ 65%；**H2**：路径层相对 no-path 的均值 ≤ 0 且符号一致率 ≤ 50% | **新增**：预先声明方向性判据 |
| 决策 | H1 过且 Holm<0.05 → 写"外部复现的角色层增益"；H1 不过 → 写"未能复现"并给功效上限；H2 过 → 强化负结论 | 先写后跑 |

## 5. 风险与退路

| 风险 | 概率 | 影响 | 退路 |
|---|---|---|---|
| 电网事故族凑不齐 12 份 | 中高 | 该族功效不足 | 报告功效上限；把该族定位为"高质量小样本案例集"，把主要统计力量放在市场耦合族 |
| 许可不允许再分发 | 中 | 不能发布语料 | 只发布非逐字派生物（脚本 + 逐文档指标 + 清单哈希），语料由使用者自行获取（现有做法） |
| 参考章节缺失/过短 | 中 | 文档被门禁排除 | 记录排除理由与数量；不要为凑数放宽到"摘要 <100 词" |
| 两页并排/多栏导致解析错位 | 中 | 单元质量下降 | 版式感知抽取（字号过滤页眉）+ 人工抽检 5 份 |
| 家族内 n 仍偏小 | 中 | 结论"不显著" | 已在协议中强制报告功效上限，避免误读 |
| 效果方向与内部相反 | 低 | 叙事受冲击 | 按判据如实写为"边界条件"，这正是诊断论文的合法内容 |

## 6. 不做清单（红线）

1. 不把合成数据或机器标签写成专家标注；E2 三道前置（未见系列 / 独立标注者 / 伦理决定）不因本计划而关闭。
2. 不把市场耦合族与电网事故族合并统计，不与历史 15 题或 7 系列合并成"总准确率"。
3. 不在测试集上做任何调参；如需开发集，按系列（非文档）切分并在协议中冻结。
4. 不因"想要显著"而放宽参考定义、去重规则或候选门禁。
5. 不把"p 不显著"写成"效应不存在"——必须同时给出功效上限与零质量。

## 7. 成功/失败的定义（先说清）

| 结果 | 判定 | 论文处置 |
|---|---|---|
| H1 过（角色层符号一致率 ≥65% 且 Holm<0.05），H2 过 | 外部复现成功 | 升级：新增外部复现小节 + 补充表，摘要更新 |
| H1 过，H2 不过 | 部分复现 | 写"角色层可复现、路径层未能复现负效应"，并给功效上限 |
| H1 不过，H2 过 | 负结论强化 | 强化"类型化路径不携带信息"的结论，角色层降为"内部证据" |
| 两者都不过 | 功效不足或效应不存在 | 如实写"未检出，且该族功效上限为 p_min=k·2/2ⁿ"，不升级主张 |
