## 使用边界

- 当前证据支持确定性、可溯源的技术报告摘要框架及路径项负向诊断，不支持把路径删除解释为性能增益。
- equal-unit 比较存在明显输出长度差异，不能写成公平预算下优于 Semantic-MMR 或 TextRank。
- 角色、边、路径和工程效用尚缺直接人工验证。
- 通讯作者信息、全体作者确认、数据/图表权利和外部专家/外部序列验证仍为投稿前硬门槛。
- `90_Archive/` 只作历史溯源，不是当前稿件来源。
