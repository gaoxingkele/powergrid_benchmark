# C2GES Optional Figure Upgrade

This folder contains an optional visual upgrade candidate generated after the
required supplement artifact collection was assembled.

Files:

- `c2ges_teaser_architecture_upgrade.png` - optional teaser / architecture
  upgrade candidate for the C2GES paper.
- `c2ges_teaser_architecture_upgrade_prompt.txt` - curated method prompt used
  for the direct AutoFigure-Edit PNG generation.
- `manifest.json` - provenance and visual-gate notes.

The image was not inserted into the original manuscript PDF. It is provided as
an optional candidate for later author review before any manuscript replacement
or graphical-abstract submission.
