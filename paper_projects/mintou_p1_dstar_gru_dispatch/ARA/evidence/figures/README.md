# Figures

The submission figures for this paper are **not** stored here. They live with the manuscript at:

`mintou_p1_dstar_gru_dispatch/manuscript/figures/`

- `fig_benchmark_overview.png` — benchmark target series, sparsity, onset definition (Fig. 1)
- `fig_leaderboard.png` — per-horizon leaderboards, MAE and onset F1 (Fig. 2)
- `fig_scale_dependency.png` — Holm-corrected scale-dependence result (Fig. 3)

All three are 300 dpi PNGs regenerated by `manuscript/figures/make_figures.py`, which also
writes the series statistics quoted in the manuscript (`series_stats.json`,
`cap_sensitivity.json`).

Historical note: an earlier version of this file said figures would be generated "after public
benchmark result tables are upgraded beyond synthetic smoke tests" — that referred to the
deprecated v3 proxy pipeline (`real_rts_dispatch_*`). The current evaluation is
`public_rts_curtailment_v5_onset_eval`; see the manuscript's Section III-F for the provenance.
