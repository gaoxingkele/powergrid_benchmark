# 闽投六篇：写作与实验流程回顾及标准化 Harness

## 1. 组合目标与最终状态

六篇论文不是一篇稿件的六个版本，而是面向不同电网任务、不同期刊的独立研究单元。
流程最终形成了六套 Markdown 主文、期刊 LaTeX/PDF、独立证据树、统计结果、图表、
三轮评审记录和完整投稿 ZIP。当前 PDF 为 P1 15 页、P2 19 页、P3 22 页、P4 25 页、
P5 24 页、P6 24 页；图数分别为 8、8、9、9、8、9，表数为 6、5、8、8、6、7。
这些数量是当前产物描述，不是期刊录用保证，也不应作为以后机械扩写的目标。

## 2. 实际形成的端到端流程

### 阶段 A：论文身份与贡献边界

先固定每篇的任务、目标期刊、标题和核心贡献，再分配独立的正文目录和 evidence 目录。
这个阶段解决的主要风险是六篇之间的数据、表述和方法贡献相互串用。以后新增论文时，
必须先创建独立 paper ID、目标期刊、贡献声明和证据根，才能进入检索或实验阶段。

### 阶段 B：同期刊比较与篇幅预算

每篇按目标期刊选取至少十篇电网主题或方法相近论文，比较章节篇幅、段落密度、公式、
图表、数据集、实验矩阵、统计方法和句式。比较结果用于发现缺口，不能把均值理解为录用
阈值。最有效的做法是先问“缺少哪类证据”，再决定是否增加文字、公式或图表；单纯追求
数量会造成重复段落和无证据的理论包装。

### 阶段 C：实验登记、冻结和预检

实验增强前先冻结数据切分、方法、基线、随机种子、主指标、统计检验和失败处理策略。
本组合的冻结协议及 SHA-256 已写入 `profile.json`。预检包括路径、输入、运行环境、
统计代码单元测试和输出目录隔离。冻结后若发现错误，应形成修订协议和新哈希，而不是在
原运行目录静默修补。

### 阶段 D：正式实验与证据树

每篇证据树统一保留 `source/`、`runs/`、`tables/`、`figures/` 及 README。原始运行
输出和失败记录是不可变材料；论文表格和图片是派生材料。正式重跑必须进入新目录并记录
代码版本、数据版本、环境、种子、起止时间和资源。跨论文共用公开数据时，仍需在各自的
实验清单中说明处理、切分和用途。

### 阶段 E：统计审计和声明约束

从原始运行构造排行榜、配对差异、置信区间、效应量、多重比较校正和稳健性分析。测试脚本
用于防止统计实现回归。非显著结果、反向结果和适用范围限制必须进入结果与结论，不能因
“数据不好看”而删除。统计显著性、工程意义和泛化范围分别表述，避免把单数据集优势写成
普遍优越性。

### 阶段 F：逐章节写作与图表血缘

正文按“问题—缺口—贡献—方法—实验问题—结果—限制—结论”闭环组装。每个定量句要能
回到 evidence 表，每个图表要有生成脚本或明确源文件。架构图解释模块与信息流，结果图
解释比较与不确定性，两者不互相替代。公式只用于定义目标、机制或统计量，不用装饰性推演
填充理论深度。

### 阶段 G：三轮独立评审和修改

三位评审角色分别覆盖：内在逻辑与写作、方法与统计、理论与创新。第一轮定位实质问题，
第二轮核验修改是否真正闭环，第三轮做声明—证据—结论一致性和投稿阻断项检查。所有轮次
保留独立意见与最终 closure，避免只保留“已修改”的结论而丢失审计链。

### 阶段 H：构建、视觉 QA、独立性检查与打包

最终构建检查页数、图表、缺字、未定义引用、参考文献和模板。打包时必须包含源文件、PDF、
图片、允许分发的数据/证据、生成或验证脚本和说明，不能只放 PDF。六个 ZIP 的哈希在
profile 中固定。任何正文变化都会使发布哈希失效，必须走新的发布批次。

### 阶段 I：人工投稿门禁

作者顺序、单位、通信邮箱、CRediT、基金、利益冲突、数据许可、APC 和最终投稿操作由作者
确认。Harness 不发送邮件、不创建投稿账户、不代替作者作版权或数据权利声明。

## 3. 关键经验

1. 先固定证据边界，再扩写文章，能显著减少“文字比实验走得更远”的问题。
2. 期刊比较最有价值的是识别缺少的实验问题和统计证据，不是追求页数均值。
3. 正文、证据树和最终 ZIP 必须各有唯一权威位置；复制件只用于交付，不能反向成为主版本。
4. 图表重绘必须保留数据血缘；生成式图片适合概念示意，不适合生成数值曲线或实验结果。
5. 三轮评审必须验证证据，而不是三次语言润色。

## 4. 变更协议

今后修改任一论文时按以下顺序执行：新建变更记录 → 判断是否影响冻结协议 → 如影响则新建
实验版本和运行目录 → 重建统计材料 → 更新正文与图表 → 三维度复核 → PDF/视觉 QA → 新建
发布目录与 ZIP → 更新 profile 哈希。只改作者信息且不影响正文时，也应重建最终 PDF/ZIP，
但无需重跑实验。
