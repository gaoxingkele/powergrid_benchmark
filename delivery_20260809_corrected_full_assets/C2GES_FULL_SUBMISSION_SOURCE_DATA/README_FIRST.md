# C2GES complete submission package — open this file first

This is the corrected full-asset package prepared on 2026-08-09.

The six required top-level folders are intentionally separated:

1. `00_PDF/` — final 25-page manuscript PDF;
2. `01_LaTeX_Source/` — editable `.tex`, `.bib`, generated `.bbl`, MDPI class/definition files, and build script;
3. `02_Figures/` — 14 figure and lineage/source files in PDF, PNG, SVG, JSON, and Python formats;
4. `03_Code/` — 17 analysis, verification, packaging, and regression-test files;
5. `04_Data/` — 52 rights-safe result, protocol, diagnostic, metadata, figure-input, and calibration files;
6. `05_Reviews_Audits/` — 16 review, rights, incident, citation, visual, and reproducibility audit files.

The public repository is <https://github.com/gaoxingkele/c2ges>.

Restricted NERC PDFs and verbatim derived text, model weights, credentials, and `.env` files are excluded. Yang Yong is the corresponding author; create and verify an independent email account controlled by Yang Yong and replace the temporary correspondence address before submission.

`CONTENTS_AND_SHA256.csv` provides the relative path, category, byte size, and SHA-256 digest for every included file.
